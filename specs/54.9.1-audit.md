## Section 4: Master Prompts Update

**Question:** How did the master prompts get updated, and what's their current state?

Inspect:
- `project_configurations.master_prompts` for toolwiki — query the active version
- Any migration files or one-off scripts in `packages/db/src/migrations/` or `scripts/` from Spec 54.9 implementation

**Document:**
- Were placeholders `{{SOURCE_CONTEXT}}` and `{{TOOLS_CONTEXT}}` actually added to toolwiki's master prompts?
- Which master prompt keys got the placeholders: just `article.outline` + `article.draft`, or all 6 keys?
- Where exactly in the prompt template is the placeholder positioned (start, middle, end)?
- Any other placeholders that got added that weren't in the spec?
- Was there a migration file (e.g. `0044_...`) or just a manual SQL run?

**SQL to run:**
```sql
-- See current state of toolwiki master prompts
SELECT 
  key,
  CASE 
    WHEN prompt LIKE '%{{SOURCE_CONTEXT}}%' THEN 'YES'
    ELSE 'no'
  END AS has_source_context,
  CASE 
    WHEN prompt LIKE '%{{TOOLS_CONTEXT}}%' THEN 'YES'
    ELSE 'no'
  END AS has_tools_context,
  LENGTH(prompt) AS prompt_length,
  updatedAt
FROM (
  SELECT 
    jsonb_object_keys(master_prompts) AS key,
    master_prompts AS mp
  FROM project_configurations
  WHERE project_id = (SELECT id FROM projects WHERE slug = 'toolwiki')
    AND status = 'active'
) sub,
LATERAL (
  SELECT 
    mp -> key ->> 'prompt' AS prompt,
    mp -> key ->> 'updatedAt' AS updatedAt
) extracted;
```

**Output format:** Table of keys + flags + 1-2 paragraphs interpretation.

## Section 6: Real-World Cost Per Article

**Question:** What's the actual cost per generated DE blog article vs. the €1.17 estimate?

Inspect:
- `cost_logs` for any blog articles generated since Spec 54.9 deployment

**Document:**
- Number of blog articles generated through the new pipeline so far
- Per-article cost breakdown by operation (use SQL below)
- Comparison to estimate: Outline €0.15, Draft €0.40, SelfReview €0.04, Schema €0.55, Hero €0.03 = €1.17
- Any unexpected operations adding cost (validation retries, JSON mode failures, etc.)
- Token budget surprises: are prompts longer than expected? Are outputs hitting max_tokens?

**SQL to run:**
```sql
-- Find blog articles generated since the new pipeline went live
WITH blog_articles AS (
  SELECT 
    id,
    title,
    created_at
  FROM articles
  WHERE collection = 'blog'
    AND source = 'generated'
    AND project_id = (SELECT id FROM projects WHERE slug = 'toolwiki')
    AND created_at > '2026-05-15'  -- adjust to your 54.9 deployment date
  ORDER BY created_at DESC
)
SELECT 
  ba.id,
  ba.title,
  ba.created_at,
  ROUND(SUM(cl.cost_eur)::numeric, 4) AS total_cost,
  COUNT(DISTINCT cl.operation) AS op_count,
  jsonb_object_agg(cl.operation, ROUND(SUM(cl.cost_eur)::numeric, 4)) FILTER (WHERE cl.operation IS NOT NULL) AS cost_by_op
FROM blog_articles ba
LEFT JOIN cost_logs cl ON cl.article_id = ba.id
GROUP BY ba.id, ba.title, ba.created_at
ORDER BY ba.created_at DESC
LIMIT 10;

-- If no articles yet generated through new pipeline, report that
```

**Output format:** SQL results table + 1 paragraph commentary.
