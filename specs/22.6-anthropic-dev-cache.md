## Context

Every LLM call in the Marketing-Tool flows through one entry-point: `anthropic.messages(input)` in `packages/adapters/anthropic/src/client.ts`. This is the chokepoint for cost.

In **production** these calls cost real money — Cold-Start for toolwiki costs ~$15-20, ongoing cluster generation ~$2-5 per cluster.

In **dev**, the same calls run repeatedly during testing, debugging, and iteration. Without caching, each test run hits the API fresh — costs accumulate quickly without any added value (same prompts return the same answers).

This spec adds a **fixture-based cache layer** at the adapter level:
- **Production**: behavior unchanged. Live API calls every time.
- **Dev with cache MISS**: makes a real API call, records the response to disk.
- **Dev with cache HIT**: replays the recorded response. **Zero cost.**
- **Dev with `force-refresh`**: bypasses cache, always live (for re-recording).

The cache key is deterministic — same prompts → same key → same response. Cache files are committed to git so the team shares fixtures.

This is the standard "VCR/cassette" pattern, well-established in test infrastructure (Ruby's VCR, Python's vcrpy, JS's nock-record).

## Goal

After this spec:
- New env-var: `ANTHROPIC_CACHE_MODE` (`off` | `replay` | `record` | `auto`, default `off`)
- Cache fixtures stored at `packages/adapters/anthropic/fixtures/<sha256-prefix>.json`
- Determinism: same `MessagesInput` → same cache key → same fixture
- Modes:
  - `off` (default, prod): no caching, always live
  - `replay`: only replay; cache miss = error (good for CI)
  - `record`: always live, write fixture (good for first run)
  - `auto`: replay if cached, record if missing (developer-friendly)
- New `forceRefresh?: boolean` field on `MessagesInput` to bypass cache for one call (re-record)
- Cost-tracker records `eur=0` and `cached=true` for replayed responses
- Fixture-management CLI: list, prune, redact

## Non-Goals

- **No request-fuzzy-matching** — cache hits require byte-exact key match. Different prompts = different fixtures.
- **No automatic redaction of PII in fixtures** — manual redact-cli helper provided, but operator responsibility.
- **No cache for live web-search results** — calls with `webSearch.enabled=true` are never cached (results stale fast, plus search-results may be from gated content).
- **No cross-project cache sharing** — `projectId` is part of the cache key (intentional: different projects may have different conventions).
- **No cache-eviction-by-TTL** — fixtures are permanent until manually pruned. Encourages explicit re-recording when prompts change.
- **No frontend UI changes** — fully backend.

## Architecture Overview

```
┌──────────────────────────────────────────────────────────────────┐
│  pipeline step / worker calls:                                   │
│    anthropic.messages({ projectId, model, systemPrefix, ... })  │
└────────────────────────────┬─────────────────────────────────────┘
                             │
                             ▼
┌──────────────────────────────────────────────────────────────────┐
│  Cache wrapper (NEW)                                             │
│  - Compute cache key: sha256(canonicalized MessagesInput minus   │
│    pipelineRunId, articleId — those vary per run but not output) │
│  - Mode dispatch:                                                │
│    * off       → call live, return                               │
│    * replay    → load fixture; if missing, throw                 │
│    * record    → call live, write fixture                        │
│    * auto      → load fixture if exists; else call live + write  │
│  - For replay: skip assertCostBudget, log cached=true, return    │
└────────────────────────────┬─────────────────────────────────────┘
                             │ if not replayed:
                             ▼
┌──────────────────────────────────────────────────────────────────┐
│  Existing live API path                                          │
│  - assertCostBudget                                              │
│  - SDK call                                                      │
│  - track() cost                                                  │
└──────────────────────────────────────────────────────────────────┘
```

**Cache key inputs** (deterministic):
- `model`
- `systemPrefix`
- `systemSuffix`
- `userMessage`
- `maxTokens`, `temperature`, `topP`, `topK` (or defaults)
- `jsonMode`
- `tools` if defined
- NOT included: `projectId`, `pipelineRunId`, `articleId`, `operation`, `estimatedCostEur` — these affect tracking, not LLM output

**Why not include `projectId`**: same prompts produce same output regardless of which project requested them. Including it would defeat sharing fixtures across projects (the test-toolwiki cold-start can serve as fixture for similar projects).

**Why exclude `pipelineRunId` / `articleId`**: these are run-correlation IDs that change every run. Including them would make every call a cache miss.

```typescript
export type CacheMode = "off" | "replay" | "record" | "auto";

/** What gets persisted to disk per cache hit. */
export interface CachedResponse {
  /** Cache schema version — bump if fixture format changes */
  schemaVersion: 1;
  /** ISO timestamp when this fixture was recorded */
  recordedAt: string;
  /** The model + prompt-hash this was generated for, for human inspection */
  metadata: {
    model: string;
    systemPrefixLen: number;
    systemSuffixLen: number;
    userMessageLen: number;
    jsonMode: boolean;
    operation: string;
    /** First 80 chars of userMessage for human grepping */
    userMessagePreview: string;
  };
  /** Full response (matches MessagesResult except cacheStats are zeroed for replay) */
  response: MessagesResult;
}
```

### A.3 Cache module

```typescript
// packages/adapters/anthropic/src/cache.ts
import { createHash } from "node:crypto";
import { existsSync, mkdirSync, readFileSync, readdirSync, writeFileSync } from "node:fs";
import { join } from "node:path";
import { createLogger, getEnv } from "@marketing-auto/shared";
import type { CacheMode, CachedResponse } from "./cache-types.ts";
import type { MessagesInput, MessagesResult } from "./types.ts";

const log = createLogger("anthropic:cache");

/** Where fixtures live — under the package root, committed to git */
const FIXTURES_DIR = (() => {
  // import.meta.dirname works in Bun + ESM
  const here = import.meta.dirname;
  // packages/adapters/anthropic/src → packages/adapters/anthropic/fixtures
  return join(here, "..", "fixtures");
})();

/** Resolve cache mode from env, falling back to "off". */
export function getCacheMode(): CacheMode {
  const env = getEnv();
  const raw = (env.ANTHROPIC_CACHE_MODE ?? "off").toLowerCase().trim();
  if (raw === "replay" || raw === "record" || raw === "auto" || raw === "off") {
    return raw;
  }
  log.warn(
    { value: env.ANTHROPIC_CACHE_MODE },
    "Unknown ANTHROPIC_CACHE_MODE — falling back to 'off'"
  );
  return "off";
}

/**
 * Compute deterministic cache key from MessagesInput.
 *
 * Includes only fields that affect the LLM output. Excludes run-correlation
 * IDs (pipelineRunId, articleId), tracking metadata (operation,
 * estimatedCostEur), and runtime context (projectId — see Non-Goals).
 *
 * Returns first 16 hex chars of sha256 → 16^16 possible keys, collision
 * probability ~1e-15 for any realistic fixture-set size.
 */
export function computeCacheKey(input: MessagesInput): string {
  const canonical = {
    model: input.model,
    systemPrefix: input.systemPrefix,
    systemSuffix: input.systemSuffix,
    userMessage: input.userMessage,
    maxTokens: input.maxTokens ?? null,
    temperature: input.temperature ?? null,
    topP: input.topP ?? null,
    topK: input.topK ?? null,
    jsonMode: input.jsonMode ?? false,
    cacheTtl: input.cacheTtl ?? null,
    // webSearch intentionally NOT included — see Non-Goals
  };
  const canonicalJson = JSON.stringify(canonical);
  return createHash("sha256").update(canonicalJson).digest("hex").slice(0, 16);
}

/** Path on disk for a given cache key. */
export function fixturePath(cacheKey: string): string {
  return join(FIXTURES_DIR, `${cacheKey}.json`);
}

/** Whether webSearch is enabled — those calls are never cached. */
export function isCacheable(input: MessagesInput): boolean {
  return !(input.webSearch?.enabled === true);
}

/**
 * Read a fixture from disk. Returns null if missing.
 * Throws if file exists but is malformed.
 */
export function readFixture(cacheKey: string): CachedResponse | null {
  const path = fixturePath(cacheKey);
  if (!existsSync(path)) return null;
  try {
    const raw = readFileSync(path, "utf-8");
    const parsed = JSON.parse(raw) as CachedResponse;
    if (parsed.schemaVersion !== 1) {
      log.warn(
        { cacheKey, version: parsed.schemaVersion },
        "Fixture has unexpected schema version — ignoring (treat as miss)"
      );
      return null;
    }
    return parsed;
  } catch (e) {
    log.error({ cacheKey, err: e }, "Failed to parse fixture — treating as miss");
    return null;
  }
}

/** Write a fixture to disk, creating directory if needed. */
export function writeFixture(
  cacheKey: string,
  input: MessagesInput,
  response: MessagesResult
): void {
  if (!existsSync(FIXTURES_DIR)) {
    mkdirSync(FIXTURES_DIR, { recursive: true });
  }

  const fixture: CachedResponse = {
    schemaVersion: 1,
    recordedAt: new Date().toISOString(),
    metadata: {
      model: input.model,
      systemPrefixLen: input.systemPrefix.length,
      systemSuffixLen: input.systemSuffix.length,
      userMessageLen: input.userMessage.length,
      jsonMode: input.jsonMode ?? false,
      operation: input.operation,
      userMessagePreview: input.userMessage.slice(0, 80),
    },
    // Zero out cacheStats — these reflect Anthropic's prompt-cache, not our fixture cache
    response: {
      ...response,
      cacheStats: { cacheReadInputTokens: 0, cacheCreationInputTokens: 0 },
    },
  };

  writeFileSync(fixturePath(cacheKey), JSON.stringify(fixture, null, 2), "utf-8");
  log.debug({ cacheKey, operation: input.operation }, "Recorded fixture");
}

/** List all fixture files (for the CLI and prune). */
export function listFixtures(): Array<{ cacheKey: string; fixture: CachedResponse }> {
  if (!existsSync(FIXTURES_DIR)) return [];
  const files = readdirSync(FIXTURES_DIR).filter((f) => f.endsWith(".json"));
  const out: Array<{ cacheKey: string; fixture: CachedResponse }> = [];
  for (const f of files) {
    const cacheKey = f.replace(/\.json$/, "");
    const fixture = readFixture(cacheKey);
    if (fixture) out.push({ cacheKey, fixture });
  }
  return out;
}
```

## Section B — Wire Cache into messages()

### B.1 File modified

### B.2 Wire-up

The existing `messages()` flow:
1. assertCostBudget
2. getClient
3. build system blocks + tools
4. SDK call
5. track() cost
6. parse JSON if needed
7. return MessagesResult

The cache check goes **at the top**, before assertCostBudget (replays cost nothing → no budget assertion needed):

```typescript
// packages/adapters/anthropic/src/client.ts
import {
  computeCacheKey,
  getCacheMode,
  isCacheable,
  readFixture,
  writeFixture,
} from "./cache.ts";

export async function messages(input: MessagesInput): Promise<MessagesResult> {
  // Cache layer (dev-mode only — production has ANTHROPIC_CACHE_MODE=off)
  const mode = getCacheMode();
  const canCache = isCacheable(input) && !input.forceRefresh;

  if (mode !== "off" && canCache) {
    const cacheKey = computeCacheKey(input);
    const fixture = readFixture(cacheKey);

    // REPLAY mode: must have fixture, else error
    if (mode === "replay") {
      if (!fixture) {
        throw new AnthropicClientError(
          `Cache MISS for key ${cacheKey} (operation: ${input.operation}). ` +
          `In replay mode, missing fixtures are errors. ` +
          `To record, set ANTHROPIC_CACHE_MODE=record or =auto and re-run.`
        );
      }
      log.info(
        { cacheKey, operation: input.operation, recordedAt: fixture.recordedAt },
        "Anthropic cache HIT (replay)"
      );
      // Track as zero-cost cached call (for visibility in cost-logs)
      await track({
        projectId: input.projectId,
        pipelineRunId: input.pipelineRunId ?? null,
        articleId: input.articleId ?? null,
        service: "anthropic",
        operation: input.operation,
        units: 1,
        eur: 0,
        meta: { cached: true, cacheKey, source: "fixture" },
      });
      return fixture.response;
    }

    // AUTO mode: replay if exists, else fall through to live + record
    if (mode === "auto" && fixture) {
      log.info(
        { cacheKey, operation: input.operation, recordedAt: fixture.recordedAt },
        "Anthropic cache HIT (auto)"
      );
      await track({
        projectId: input.projectId,
        pipelineRunId: input.pipelineRunId ?? null,
        articleId: input.articleId ?? null,
        service: "anthropic",
        operation: input.operation,
        units: 1,
        eur: 0,
        meta: { cached: true, cacheKey, source: "fixture" },
      });
      return fixture.response;
    }

    // RECORD mode or AUTO miss: fall through to live call, then record below
  }

  // ============ EXISTING LIVE PATH (unchanged) ============
  await assertCostBudget(
    input.projectId,
    "anthropic",
    estimateCostEur("anthropic", input.operation)
  );

  const client = await getClient();
  // ... existing SDK call logic ...
  // ... existing track() call ...
  // ... existing JSON parse ...

  const result: MessagesResult = {
    raw,
    json,
    outputTokens,
    cacheStats,
    stopReason,
    messageId,
  };

  // Record fixture if in record/auto mode
  if (canCache && (mode === "record" || mode === "auto")) {
    const cacheKey = computeCacheKey(input);
    try {
      writeFixture(cacheKey, input, result);
      log.info(
        { cacheKey, operation: input.operation, mode },
        "Recorded Anthropic fixture"
      );
    } catch (e) {
      log.warn({ err: e, cacheKey }, "Failed to write fixture (continuing)");
    }
  }

  return result;
}
```

```typescript
#!/usr/bin/env bun
// packages/adapters/anthropic/src/scripts/fixtures-cli.ts
import { unlinkSync } from "node:fs";
import { listFixtures, fixturePath } from "../cache.ts";

const cmd = process.argv[2];

function fmtSize(bytes: number): string {
  if (bytes < 1024) return `${bytes}B`;
  if (bytes < 1024 * 1024) return `${(bytes / 1024).toFixed(1)}KB`;
  return `${(bytes / (1024 * 1024)).toFixed(1)}MB`;
}

if (cmd === "list" || !cmd) {
  const fixtures = listFixtures();
  if (fixtures.length === 0) {
    console.log("No fixtures recorded.");
    process.exit(0);
  }
  console.log(`Found ${fixtures.length} fixture(s):\n`);
  for (const { cacheKey, fixture } of fixtures.sort(
    (a, b) => a.fixture.recordedAt.localeCompare(b.fixture.recordedAt)
  )) {
    const date = fixture.recordedAt.slice(0, 19).replace("T", " ");
    console.log(
      `  ${cacheKey}  ${date}  ${fixture.metadata.model.padEnd(20)}  ${fixture.metadata.operation.padEnd(28)}  "${fixture.metadata.userMessagePreview}"`
    );
  }
  process.exit(0);
}

if (cmd === "show") {
  const cacheKey = process.argv[3];
  if (!cacheKey) {
    console.error("Usage: fixtures show <cacheKey>");
    process.exit(1);
  }
  const fixtures = listFixtures();
  const match = fixtures.find((f) => f.cacheKey === cacheKey);
  if (!match) {
    console.error(`Fixture ${cacheKey} not found.`);
    process.exit(1);
  }
  console.log(JSON.stringify(match.fixture, null, 2));
  process.exit(0);
}

if (cmd === "delete") {
  const cacheKey = process.argv[3];
  if (!cacheKey) {
    console.error("Usage: fixtures delete <cacheKey>");
    process.exit(1);
  }
  try {
    unlinkSync(fixturePath(cacheKey));
    console.log(`Deleted fixture ${cacheKey}`);
  } catch (e) {
    console.error(`Failed: ${(e as Error).message}`);
    process.exit(1);
  }
  process.exit(0);
}

if (cmd === "prune") {
  // Prune fixtures older than N days
  const daysArg = process.argv[3];
  const days = daysArg ? parseInt(daysArg, 10) : 30;
  if (!Number.isFinite(days) || days < 1) {
    console.error("Usage: fixtures prune [days] (default 30)");
    process.exit(1);
  }
  const cutoff = Date.now() - days * 24 * 60 * 60 * 1000;
  const fixtures = listFixtures();
  let pruned = 0;
  for (const { cacheKey, fixture } of fixtures) {
    if (new Date(fixture.recordedAt).getTime() < cutoff) {
      unlinkSync(fixturePath(cacheKey));
      pruned += 1;
      console.log(`  pruned ${cacheKey} (${fixture.recordedAt})`);
    }
  }
  console.log(`\nPruned ${pruned} fixture(s) older than ${days} days.`);
  process.exit(0);
}

console.error("Usage: fixtures <list|show|delete|prune> [args]");
console.error("");
console.error("  list                       — list all fixtures with metadata");
console.error("  show <cacheKey>            — print full fixture content");
console.error("  delete <cacheKey>          — delete one fixture");
console.error("  prune [days]               — delete fixtures older than N days (default 30)");
process.exit(1);
```

```typescript
// packages/adapters/anthropic/test/cache.test.ts
import { afterEach, describe, expect, test } from "bun:test";
import { existsSync, readFileSync, rmSync } from "node:fs";
import {
  computeCacheKey,
  fixturePath,
  isCacheable,
  readFixture,
  writeFixture,
} from "../src/cache.ts";
import type { MessagesInput, MessagesResult } from "../src/types.ts";

const baseInput: MessagesInput = {
  projectId: "00000000-0000-0000-0000-000000000001",
  operation: "test",
  model: "sonnet-4-6",
  systemPrefix: "You are helpful.",
  systemSuffix: "Be concise.",
  userMessage: "What is 2+2?",
  jsonMode: false,
  estimatedCostEur: 0.01,
};

const baseResult: MessagesResult = {
  raw: "4",
  json: null,
  outputTokens: 1,
  cacheStats: { cacheReadInputTokens: 0, cacheCreationInputTokens: 0 },
  stopReason: "end_turn",
  messageId: "msg_test",
};

const testKeysToCleanup: string[] = [];

afterEach(() => {
  for (const k of testKeysToCleanup) {
    const p = fixturePath(k);
    if (existsSync(p)) rmSync(p);
  }
  testKeysToCleanup.length = 0;
});

describe("cache key", () => {
  test("same input → same key", () => {
    const k1 = computeCacheKey(baseInput);
    const k2 = computeCacheKey({ ...baseInput });
    expect(k1).toBe(k2);
  });

  test("different userMessage → different key", () => {
    const k1 = computeCacheKey(baseInput);
    const k2 = computeCacheKey({ ...baseInput, userMessage: "What is 3+3?" });
    expect(k1).not.toBe(k2);
  });

  test("different projectId → SAME key (excluded from key)", () => {
    const k1 = computeCacheKey(baseInput);
    const k2 = computeCacheKey({
      ...baseInput,
      projectId: "00000000-0000-0000-0000-000000000099",
    });
    expect(k1).toBe(k2);
  });

  test("different pipelineRunId → SAME key (excluded)", () => {
    const k1 = computeCacheKey(baseInput);
    const k2 = computeCacheKey({ ...baseInput, pipelineRunId: "abc" });
    expect(k1).toBe(k2);
  });

  test("different model → different key", () => {
    const k1 = computeCacheKey(baseInput);
    const k2 = computeCacheKey({ ...baseInput, model: "haiku-4-5" });
    expect(k1).not.toBe(k2);
  });

  test("changing systemPrefix → different key", () => {
    const k1 = computeCacheKey(baseInput);
    const k2 = computeCacheKey({ ...baseInput, systemPrefix: "Different prefix" });
    expect(k1).not.toBe(k2);
  });

  test("jsonMode change → different key", () => {
    const k1 = computeCacheKey(baseInput);
    const k2 = computeCacheKey({ ...baseInput, jsonMode: true });
    expect(k1).not.toBe(k2);
  });
});

describe("isCacheable", () => {
  test("normal input is cacheable", () => {
    expect(isCacheable(baseInput)).toBe(true);
  });
```

## Dev-Mode Response Cache

To save Anthropic API costs during development, the adapter supports a
fixture-based replay cache controlled by `ANTHROPIC_CACHE_MODE`:

- `off` (default, production): always live API
- `auto`: replay if cached, else call live + record
- `record`: always live, always record
- `replay`: only replay; cache miss = error

Fixtures live in `packages/adapters/anthropic/fixtures/<sha256-prefix>.json`.
They are committed to git so the team shares them.

### Workflow

1. First-time cold-start (or any new prompts): set `ANTHROPIC_CACHE_MODE=auto`,
   run the pipeline once. Real API calls happen, fixtures are recorded.
2. Subsequent dev work: `ANTHROPIC_CACHE_MODE=auto` (or `replay` for strict).
   All cached calls return $0 instantly.
3. When a prompt changes, its cache key changes → next run does a live call
   and records a new fixture. The old one becomes orphan; prune occasionally.
4. Force re-record one call: pass `forceRefresh: true` in `MessagesInput`.

### Hard Rules

- Never enable `record` or `auto` in production. Set `ANTHROPIC_CACHE_MODE=off`
  in prod env. The default is `off` (safe).
- Web-search calls (`webSearch.enabled=true`) are never cached.
- Replay-mode in CI gives reproducibility but requires committed fixtures
  for every prompt the test path touches.
- Don't commit fixtures with sensitive content. Use `bun --filter
  @marketing-auto/adapter-anthropic fixtures show <key>` to inspect before
  committing.

## Discovered During Implementation

1. **`ANTHROPIC_CACHE_MODE` must be added to `getEnv()` Zod schema** — Spec assumed `getEnv().ANTHROPIC_CACHE_MODE` would work, but `getEnv()` is a strict Zod schema; unknown keys fail at compile time. Added using the preprocess-enum pattern (per CLAUDE.md rule for optional enum env vars):
   ```typescript
   ANTHROPIC_CACHE_MODE: z.preprocess(
     (v) => (v === "" ? undefined : v),
     z.enum(["off", "replay", "record", "auto"]).optional()
   ),
   ```

2. **`track()` API shape for cached zero-cost calls** — Spec pseudocode used `track({ units, eur, meta })` which doesn't match the real signature. The correct pattern for logging a zero-cost operation through `track()` is:
   ```typescript
   await track({
     projectId, service, operation, estimatedCostEur: 0,
     fn: async () => null,
     computeCostEur: () => 0,
     metadata: () => ({ cached: true, cacheKey, source: "fixture" }),
   });
   ```
   The optional `pipelineRunId`/`articleId` fields must be spread conditionally (not passed as `undefined`) due to `exactOptionalPropertyTypes`.

3. **`CacheStats` has 5 fields, not 2** — Spec only zeroed `cacheReadInputTokens` and `cacheCreationInputTokens` in `writeFixture`. The full type also requires `totalInputTokens`, `freshInputTokens`, and `hit`.

4. **TypeScript narrowing in CLI scripts** — `if (!x) die(...)` doesn't narrow `x` after the call even with `die(): never` return type. Use the `??` pattern instead: `const x = process.argv[3] ?? die("Usage: ...")`. Works because `die(): never` makes `string | never` collapse to `string`.

## Deviations

1. **`AnthropicClientError` status arg** — Spec omitted the required `status: number` second argument in the replay-miss throw. Used `0` as the status code since fixture cache misses are local errors, not HTTP errors.

2. **Multi-line JSDoc on `computeCacheKey` and `readFixture`** — Spec included them; kept in place since the existing codebase (`types.ts`) already uses this style. Not added to other functions.

3. **`fmtSize` helper removed from CLI** — Spec defined a `fmtSize` function in fixtures-cli that was never called in any of the listed commands. Dropped to avoid an unused-variable linter warning.
