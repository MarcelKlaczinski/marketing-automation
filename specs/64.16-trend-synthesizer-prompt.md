## 1. Problem

Aus Discovery Title-Rewriter (2026-05-23):

**Smoking gun:** `packages/pipelines/src/topic-sources/trend-discovery/synthesize.ts:55-85`

Single Opus 4.7 call produziert BOTH `topic_title` (clean) AND `suggested_title` (drama) in derselben JSON response. Kein downstream rewrite-step. `suggested_title` wird verbatim durch alle stages gepiped (planner, pipeline-router, persist).

**Current prompt-knob:**
> "suggested_title: A compelling article headline (10–200 chars). Should include the primary keyword naturally."

Das Wort **"compelling"** interpretiert LLM als "make it click-worthy" → drama framing.

**Beispiel-Bug (Marcel 2026-05-23):**
- topic_title: `KI-Regulierung und gesellschaftliche Risiken: Deepfakes, Politik und Ethik`
- suggested_title: `KI-Regulierung 2026: Deepfakes, Executive Orders und der Kampf um Leitplanken`
- Drift: anchor swap (Politik→Executive Orders), drama injection (Kampf um), year tag added (2026:), English term mistranslated (Guardrails→Leitplanken)

**Discovery audit:** 29/29 trend_discovery briefs der letzten 30 Tage haben divergierende suggested_title (100% drift rate). Patterns:
- ~8 cases Year-Tag-added
- ~6 cases Drama-framing
- ~5 cases Anchor-swap
- ~4 cases English-term-mistranslated
- ~3 cases Question-form
- ~3 cases Section-listicle

## 3. Patch

**File:** `packages/pipelines/src/topic-sources/trend-discovery/prompts.ts` — `buildTrendSynthesisDefaultPrompt(scope)` Field Requirements section

### Current (zur Referenz):

```
# Topic Field Requirements
- **topic_title**: Concise, SEO-aware. If the project targets German users, phrase it as a German searcher would (e.g. "ChatGPT im Unternehmenseinsatz"). If English-only, use English.
- **primary_keyword**: The single most important SEO keyword. Use the language that matches the project's primary market.
- **suggested_title**: A compelling article headline (10–200 chars). Should include the primary keyword naturally.
- **suggested_slug**: URL-safe slug, lowercase, hyphens only, max 100 chars. Derive from suggested_title.
- **suggested_meta**: Meta description for search results, 50–160 chars. Must include primary keyword and a clear value proposition.
- **hero_image_prompt**: Visual brief for AI image generation, 80–800 chars. Describe composition, mood, style — no text/logos.
```

### New:

```
# Topic Field Requirements
- **topic_title**: Concise, SEO-aware. If the project targets German users, phrase it as a German searcher would (e.g. "ChatGPT im Unternehmenseinsatz"). If English-only, use English. Preserve the key concepts from the source signals — do not invent topics that aren't grounded in the inputs.

- **primary_keyword**: The single most important SEO keyword. Use the language that matches the project's primary market.

- **suggested_title**: SEO-optimized article headline (10–200 chars). Write like an SEO professional, not like a journalist. Follow these rules:
  - Include the primary_keyword naturally, ideally near the start
  - Stay close to topic_title — preserve its key anchors. The suggested_title is the SEO-tuned version of topic_title, NOT a creative rewrite. If topic_title mentions "Politik und Ethik", suggested_title should too (or a clear synonym), not swap them out for unrelated framing.
  - Use established English terms for AI/tech concepts where they are common in German content. DO NOT translate these to German: "Guardrails", "Prompts", "Embeddings", "RAG", "MCP", "Fine-Tuning", "Tool Use", "Reasoning Models", "Agents", "Agentic", "Inference", "Vector Database", "Attention", "Transformer".
  - DO NOT add year tags like "2026:" or "im Jahr 2026" unless the source signals explicitly contain a year.
  - DO NOT add dramatic framing. AVOID phrases like: "Kampf um", "Schlacht", "Krieg gegen", "Vom Hype zur", "Goldrausch", "Wenn KI", "Die dunkle Seite", "Showdown".
  - DO favor concrete value propositions (what readers learn, what gets compared, what gets solved).

- **suggested_slug**: URL-safe slug, lowercase, hyphens only, max 100 chars. Derive from suggested_title.

- **suggested_meta**: Meta description for search results, 50–160 chars. Must include primary keyword and a clear value proposition. Same anti-drama rules as suggested_title apply.

- **hero_image_prompt**: Visual brief for AI image generation, 80–800 chars. Describe composition, mood, style — no text/logos.
```

**Decision-Rationale:**
- "SEO-optimized" replaces "compelling" — the actual knob change
- "Write like an SEO professional, not like a journalist" — explicit role
- Preserve-list is concrete, not abstract ("use English terms" alone wäre zu vague)
- Drama-blocklist mit konkreten Beispielen — LLM braucht concrete don'ts statt "avoid drama"
- Anchor-preserve mit positivem Beispiel ("Politik und Ethik should stay") + negative ("nicht durch unrelated framing ersetzen")
- Year-tag policy nur on-source-evidence
- Apply same rules to `suggested_meta` (auch meta-description drama-prone)

**Out of Scope für Patch:**
- `topic_title` bleibt mostly unchanged — Discovery zeigt topic_title ist NICHT das problem (es ist clean in 100% der briefs)
- `primary_keyword` bleibt unchanged
- `suggested_slug` bleibt unchanged (derived from suggested_title — auto-correct downstream)
- `hero_image_prompt` bleibt unchanged

## 4. Tests

```ts
import { describe, it, expect } from "bun:test";
import { buildTrendSynthesisDefaultPrompt } from 
  "../../../src/topic-sources/trend-discovery/prompts";

describe("trend-synthesis prompt SEO-focus (Spec 64.16)", () => {
  const prompt = buildTrendSynthesisDefaultPrompt({ 
    projectId: "test-project",
    language: "de",
  });
  
  it("instructs SEO-optimized headlines instead of compelling/journalistic", () => {
    expect(prompt).toContain("SEO-optimized");
    expect(prompt).toContain("not like a journalist");

    expect(prompt).not.toMatch(/compelling article headline/i);

    expect(prompt).toContain("Guardrails");
    expect(prompt).toContain("Prompts");
    expect(prompt).toContain("Embeddings");
    expect(prompt).toContain("RAG");
    expect(prompt).toContain("DO NOT translate these to German");

  it("includes drama-blocklist with concrete examples", () => {
    expect(prompt).toContain("Kampf um");
    expect(prompt).toContain("Schlacht");

    expect(prompt).toMatch(/DO NOT add year tags/i);

    expect(prompt).toMatch(/Stay close to topic_title/i);
    expect(prompt).toMatch(/preserve its key anchors/i);
    expect(prompt).toMatch(/NOT a creative rewrite/i);
  });
});
```

## 7. Risiken

| Risk | Mitigation |
|---|---|
| LLM ignoriert preserve-list inkonsistent | Liste ist konkret (10+ named terms), nicht abstrakt. Plus: LLM prompts follow concrete examples better than guidance. Wenn nach 5 briefs noch Mistranslations: iterate prompt. |
| Drama-blocklist false positives (legit "Kampf gegen Vibe-Coding") | Akzeptiert. Lexikalisch blocked, Marcel kann via plan_pending review intervenieren. Wenn häufig auftritt: per-project glossar in Multi-Domain Sprint 4.4. |
| Title-Quality regression (zu nüchtern, kein engagement) | "SEO-optimized" ≠ "boring". Plus: concrete value-proposition instruction. Wenn nach 10 briefs Marcel findet titles zu trocken: iterate "favor concrete value propositions". |
| Anchor-preserve zu strikt → keine creativity | "Stay close" ist fuzzy, nicht "must include". LLM hat creative range, just no anchor-swap. |
| Year-tag policy too restrictive (Marcel wants "2026" tag manchmal) | "Unless source signals explicitly contain a year" — wenn source mentions 2026 → ok to keep. Wenn Marcel wants 2026 auto-tag: separate setting (out of scope for this spec). |
| Prompt-length increase causes token-budget overshoot | +200-400 input tokens × Opus 4.7 cached = ~€0.00001 per synthesize run. Negligible. |
| Test fails wenn prompt struktur ändert sich (z.B. Field Requirements moved) | Tests sind text-match auf keywords ("SEO-optimized", "Guardrails", "Kampf um") — überleben minor restructuring. Wenn complete prompt rewrite: tests müssen updated werden (acceptable). |
| Other LLM call sites (outline, draft, translation) still drift | Akzeptiert. synthesize ist drama-origin (100% drift rate). Downstream sites work from synthesizer's output — wenn synthesizer clean, downstream inheritance is cleaner. Wenn downstream drift persistent: separate spec (eg 64.17). |
| Marcel's existing briefs (29 in last 30d) sind already drama-tagged | Akzeptiert. Spec fixt nur FUTURE briefs. Marcel kann existing briefs manually edit ODER rejecten + re-synth. Bulk-cleanup nicht in scope. |
