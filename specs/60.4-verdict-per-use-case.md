# Spec 60.4 — `verdict-per-use-case` Remotion Composition

**Date:** 2026-05-19
**Theme:** 60 — Design System Migration
**Template key:** `verdict-per-use-case`
**Visual source:** Claude Design HTML (4 variants: dark/light × de/en)
**Prerequisite:** 60.3 done
**Estimated effort:** ~0.5 day (simplest template so far — no scores, no bullets, pure list)

---

## TL;DR

Single-slide composition. A vertical list of 5–7 use cases, each row showing an index number, a label, and a winner pill (tool icon + tool name). No scores, no bullets, no card backgrounds — just clean rows separated by `border-top`. The `.em` span in the headline uses `accent-500` (not `brand-300` like all other templates — critical difference). Glow is **top-left**, uses **`accent-500`** (not `brand-500`). Sub text is **17px** (smallest across all templates).

## Section A — Design Audit (from HTML)

### A.1 Canvas & Grid

```

Padding:        56px all sides
Grid rows:      auto auto 1fr auto   (top / hero / uc-list / foot)
Row gap:        28px
Overflow:       hidden
```

### A.2 Glow — two critical deltas vs all other templates

```
Position:       top-left  (inset: -240px auto auto -240px)
Size:           800 × 800px
Color:          color-mix(in oklab, var(--accent-500) 22%, transparent)
Blur:           filter: blur(50px)
```

**Critical — two differences from all other templates:**
1. Position is **top-left** (grid-4 = top-right, all others = bottom-left)
2. Color uses **`accent-500`** not `brand-500` — this is the only template where the glow uses the accent color

In `DsGlow` terms: `corner="top-left" alpha={22}` and a new `colorToken="accent"` prop (or equivalent).

### A.3 Top Bar — identical to all templates


No grid, no fixed heights — pure flex column. Height fills the `1fr` row.

### C.3 DsGlow — `colorToken` prop needed

This template uses `accent-500` for the glow instead of `brand-500`. Before
implementing, check if `DsGlow` already supports a `colorToken` prop. If not,
add it:

```tsx
interface DsGlowProps {
  tokens: DsTokens;
  corner: 'top-left' | 'top-right' | 'bottom-left' | 'bottom-right';
  size?: number;
  alpha?: number;         // integer 0-100
  colorToken?: 'brand' | 'accent';  // default 'brand'
}
```

Internal color resolution:
```tsx
const glowColor = colorToken === 'accent' ? tokens.accent500 : tokens.brand500;
```

### D.2 Transform function

```typescript
function transformLlmResponse(
  raw: VerdictPerUseCaseLlmResponse,
  toolLookup: ToolIconLookup,  // resolved from buildToolLookup()
): VerdictPerUseCaseGenerated {
  return {
    headline: raw.headline,
    headlineEm: raw.headline_em,
    subline: raw.subline,
    eyebrow: raw.eyebrow,
    slideNum: raw.slide_num,
    ctaLine1: raw.cta_line1,
    ctaLine2: raw.cta_line2,
    dateLabel: raw.date_label,
    useCases: raw.use_cases.map(uc => {
      const icon = toolLookup.get(uc.winner_logo_slug);
      return {
        label: uc.label,
        winnerName: uc.winner_name,
        iconSvg: icon?.iconSvg,
        iconInitials: icon?.iconInitials ?? uc.winner_name.slice(0, 2).toUpperCase(),
        iconHue: icon?.iconHue,
      };
    }),
  };
}
```

**Note:** `winner_logo_slug` is LLM-generated and used only for the `buildToolLookup()` resolution in `buildInput()`. It does NOT appear in the final `VerdictUseCase` type — only the resolved icon fields do. This follows Pattern 86.

### E.1 `VerdictPerUseCaseSlide.tsx`

```tsx
import React, { useMemo } from 'react';
import { deriveDsTokens, resolveBrandTokens } from '../../lib/brand-tokens';
import { DsGlow } from '../../ds-components/DsGlow';
import { DsTop } from '../../ds-components/DsTop';
import { DsFoot } from '../../ds-components/DsFoot';
import { ToolIconImage } from '../../ds-components/ToolIconImage';
import type { VerdictPerUseCaseProps, VerdictUseCase } from './types';

export const VerdictPerUseCaseSlide: React.FC<VerdictPerUseCaseProps> = (props) => {
  const { generated: g, brandTokens, theme } = props;

  const tokens = useMemo(
    () => deriveDsTokens(resolveBrandTokens(brandTokens), theme),
    [brandTokens, theme],
  );

  const isLight = theme === 'light';

  return (
    <div
      style={{
        width: 1080,
        height: 1350,
        backgroundColor: isLight ? 'oklch(99% 0.005 250)' : tokens.surface,
        color: tokens.ink,
        fontFamily: tokens.fontSans,
        padding: 56,
        boxSizing: 'border-box',
        position: 'relative',
        overflow: 'hidden',
        display: 'grid',
        gridTemplateRows: 'auto auto 1fr auto',
        rowGap: 28,
      }}
    >
      {/* Glow — TOP-LEFT, accent-500 color, alpha 22 */}
      <DsGlow
        tokens={tokens}
        corner="top-left"
        size={800}
        alpha={22}
        colorToken="accent"        // ← accent-500, not brand-500
      />

      <div style={{ position: 'relative', zIndex: 1, display: 'contents' }}>

        {/* TOP BAR */}
        <DsTop
          tokens={tokens}
          eyebrow={g.eyebrow}
          num={g.dateLabel}
          rightText={g.slideNum}
        />

        {/* HERO */}
        <div>
          <h1
            style={{
              fontSize: 60,
              fontWeight: 700,
              lineHeight: 1.08,
              letterSpacing: '-0.035em',
              margin: 0,
            }}
          >
            {g.headline}{' '}
            {/* accent-500 here — NOT brand-300 like all other templates */}
            <span style={{ color: tokens.accent500 }}>{g.headlineEm}</span>
          </h1>
          <p
            style={{
              fontSize: 17,                        // ← 17px (smallest across all templates)
              color: tokens.inkMuted,
              maxWidth: 880,
              lineHeight: 1.4,
              margin: '16px 0 0',                  // ← 16px top margin (others use 18px)
            }}
          >
            {g.subline}
          </p>
        </div>

        {/* USE CASE LIST */}
        <div style={{ display: 'flex', flexDirection: 'column' }}>
          {g.useCases.map((uc, i) => (
            <UseCaseRow
              key={i}
              uc={uc}
              index={i + 1}
              isLast={i === g.useCases.length - 1}
              tokens={tokens}
            />
          ))}
        </div>

        {/* FOOTER */}
        <DsFoot
          tokens={tokens}
          ctaBold={g.ctaLine1}
          ctaLead={g.ctaLine2}
        />
      </div>
    </div>
  );
};

// ─── UseCaseRow ──────────────────────────────────────────────────────────────

interface UseCaseRowProps {
  uc: VerdictUseCase;
  index: number;
  isLast: boolean;
  tokens: ReturnType<typeof deriveDsTokens>;
}

const UseCaseRow: React.FC<UseCaseRowProps> = ({ uc, index, isLast, tokens }) => (
  <div
    style={{
      display: 'grid',
      gridTemplateColumns: '48px 1fr auto',
      alignItems: 'center',
      gap: 16,
      padding: '12px 0',
      borderTop: `1px solid ${tokens.border}`,
      // Last row also gets a bottom border
      ...(isLast ? { borderBottom: `1px solid ${tokens.border}` } : {}),
    }}
  >
    {/* Index — zero-padded */}
    <div
      style={{
        fontFamily: tokens.fontMono,
        fontSize: 14,
        color: tokens.inkMuted,
        fontFeatureSettings: '"tnum"',
      }}
    >
      {String(index).padStart(2, '0')}
    </div>

    {/* Label */}
    <div
      style={{
        fontSize: 22,
        fontWeight: 600,
        lineHeight: 1.15,
        letterSpacing: '-0.02em',
      }}
    >
      {uc.label}
    </div>

    {/* Winner pill */}
    <div
      style={{
        display: 'flex',
        alignItems: 'center',
        gap: 10,
        padding: '8px 16px 8px 10px',   // asymmetric: less left (icon), more right
        background: `color-mix(in oklab, ${tokens.accent500} 14%, transparent)`,
        border: `1px solid color-mix(in oklab, ${tokens.accent500} 45%, transparent)`,
        borderRadius: 999,
      }}
    >
      <ToolIconImage
        iconSvg={uc.iconSvg}
        iconInitials={uc.iconInitials}
        iconHue={uc.iconHue}
        size={36}
        borderRadius={10}
      />
      <span
        style={{
          fontWeight: 700,
          fontSize: 17,
          letterSpacing: '-0.01em',
          color: tokens.accent500,
          whiteSpace: 'nowrap',
        }}
      >
        {uc.winnerName}
      </span>
    </div>
  </div>
);
```

```typescript
export async function renderVerdictPerUseCase(
  props: VerdictPerUseCaseProps,
  outputDir: string,
): Promise<string[]> {
  const outputPath = path.join(outputDir, 'slide-0.png');

  await renderStill({
    composition: 'verdict-per-use-case',
    serveUrl: getBundleUrl(),
    output: outputPath,
    inputProps: { ...props, slideIndex: 0 },
    imageFormat: 'png',
  });

  return [outputPath];
}
```

## Section P — Patterns Established by 60.4

**(88) `verdict-per-use-case` is the only template where the glow uses `accent-500` instead of `brand-500`. `DsGlow` needs a `colorToken` prop (`'brand' | 'accent'`, default `'brand'`). Never hardcode the color inside DsGlow — always derive from tokens.**

**(89) `verdict-per-use-case` hero `.em` span uses `tokens.accent500`, not `tokens.brand300`. This is intentional — the template's visual identity is accent-driven throughout (glow, pill, em span, winner name). Never copy `.em` color from another template without checking the HTML source.**

**(90) Variable-length list (5–7 rows) with border-bottom only on last row: use `isLast` prop on row component. The last row check is `index === items.length - 1`. Never use CSS `:last-child` pseudo-selector — Remotion does not support CSS pseudo-selectors in inline styles.**

**(91) Winner pill `white-space: nowrap` is mandatory — tool names up to 22 chars must not wrap inside the pill. If the pill would overflow the `auto` column, it pushes into the `1fr` label column via grid overflow, which is acceptable (label truncates). The pill itself never wraps.**

## Section R — Implementation Deviations & Discoveries

### R.1 `DsGlow` — `colorToken` prop was already implemented as `color`

Section C.3 and L.1 called for adding a new `colorToken: "brand" | "accent"` prop to `DsGlow`. During implementation, `DsGlow` already had `color: "brand" | "accent"` covering exactly this use case. No prop was added. Usage: `<DsGlow color="accent" ... />`. The spec's proposed prop name (`colorToken`) did not match the existing prop name (`color`); always check `src/ds-components/DsGlow.tsx` before adding new props.

### R.2 `ToolIconImage` — no `borderRadius` prop

Section E.1 used `borderRadius={10}` on `ToolIconImage`. The component has no such prop — it auto-calculates border-radius from `size` (`size * 0.22` for SVG, `"50%"` for initials avatar). The prop was silently ignored by TypeScript (not in component types) and was removed. At `size={36}`, the auto-calculated value is ~8px, close to the spec's 10px.

### R.3 `ContentBounds` values deviate from spec — REMOTION.md wins

Section D.1 specified `heroSub: { max: 120 }` and `rows.label: { min: 6, max: 32 }`. REMOTION.md (authoritative source for `bounds-match-remotion-md.test.ts`) specifies `heroSub: { max: 180 }` and `rows.label: { min: 8, max: 28 }`. REMOTION.md values were used. Similarly `rows.winnerName.max` was set to 16 (REMOTION.md) instead of 22 (spec). When spec and REMOTION.md disagree, REMOTION.md wins.

### R.4 Orphaned overrides file deleted

`src/templates/overrides/verdictCards.overrides.ts` was referenced by the old multi-slide template but no longer needed after the single-still rewrite. It was deleted in the same session.

### R.5 `contentType: "use-case"` is valid in `generateContentWithGate`

Section F mentions a custom LLM prompt for the slide content. In the implementation, slide content is built **deterministically** from `frontmatterExtras.useCaseVerdicts` (no extra LLM call). The `contentType: "use-case"` passed to `generateContentWithGate` is valid — `ContentPromptContext` accepts it and maps it to comparison-style hashtags (`#KIVergleich`). This differs from the CLAUDE.md warning about `ContentType` (used by `buildHashtagInstructions` directly), which does not have `"use-case"`.
