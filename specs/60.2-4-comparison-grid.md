## TL;DR

Implement the `comparison-grid-4` Remotion composition based on the Claude Design HTML. Single slide type (one slide per render). Layout: 4 tool cards in a fixed-height stack (`repeat(4, 150px)`), each with logo + name + verdict sentence + score + price. Winner card gets accent border + glow + flag pill. Glow is top-right (different from spotlight's bottom-left). No sub-slides, no multi-slide dispatch — one `renderStill()` call per article.

### A.1 Canvas & Grid

```

Padding:        56px all sides
Grid rows:      auto auto 1fr auto   (top / hero / stack / foot)
Row gap:        32px                  (spotlight uses 28px — different!)

### A.2 Glow

```
Position:       top-right corner (inset: -240px -240px auto auto)
Size:           800 × 800px

**Critical:** comparison-grid-4 glow is **top-right**. spotlight and comparison-grid-3 are **bottom-left**. Do not copy-paste glow CSS from spotlight without changing `inset`.

## Section B — Slide Architecture

`comparison-grid-4` renders **exactly one slide** per article. No CoverSlide/BodySlide/EndSlide split — the entire layout is one self-contained composition.

```
slideIndex 0  →  ComparisonGrid4Slide   (the only slide)
```

`renderComparisonGrid4()` in `render-server.ts` calls `renderStill()` once with `slideIndex: 0`.

Worker switch case emits exactly 1 PNG to R2.

import { z } from 'zod';

// ─── Score colour tier ────────────────────────────────────────────────────────
export type ScoreTier = 'hi' | 'mid' | 'lo';

export function scoreTier(score: number): ScoreTier {
  if (score >= 80) return 'hi';
  if (score >= 65) return 'mid';
  return 'lo';
}

// ─── LLM raw response schema (snake_case) ────────────────────────────────────
export const comparisonGrid4LlmResponseSchema = z.object({

## Deviations from Spec

### Prompt language (Sections F.2 / F.3)

The spec defined two separate prompt templates — one in German, one in English.
Implementation uses a **single English prompt** with `Output locale: ${outputLocale}` injected inline, where `outputLocale` is `"German (de), du-form"` or `"English (en)"`. The JSON skeleton field annotations likewise specify `"in German"` / `"in English"` rather than switching template bodies.

**Why:** CLAUDE.md rule — "DO NOT write LLM prompts in German — all system prompts must be in English for better instruction-following quality. Specify output language inline." Caught in `/review-task` pass.

## Section F — LLM Step & Prompt

### F.1 GenerateComparisonGrid4Step

Follows the same dual-schema pattern as `GenerateSpotlightStep` from 60.1:

1. `buildConstraintBlock(comparisonGrid4Bounds)` → injected into prompt
2. LLM call with `prompt-only JSON` (no `jsonMode: true`)
3. Extract via `raw.indexOf('{')` / `raw.lastIndexOf('}')`
4. `validateAndReprompt` against `comparisonGrid4LlmResponseSchema` (snake_case)
5. Transform → `ComparisonGrid4Generated` (camelCase)
6. Store in `content.renderInput` (snapshot pattern from 58.2)

## Section P — Patterns Established by 60.2

**(75) `comparison-grid-4` glow is top-right (`inset: -240px -240px auto auto`). All other templates default to bottom-left. `DsGlow` position prop is mandatory — never assume a default.**

**(76) Fixed-height stack rows (`repeat(4, 150px)`) require that verdict text (`verdictStrong` + `verdictRest`) combined never exceed ~2 lines at 15px. `maxChars` bounds on both fields enforce this: verdictStrong ≤ 44, verdictRest ≤ 52.**

**(77) When no tool has `isWinner: true`, the winner card UI (flag pill, accent border, glow shadow) must not render. Guard with `{tool.isWinner && ...}` — never assume at least one winner exists.**

**(78) Score font-size is template-specific: grid-4 = 84px, grid-3 = 56px, spotlight = varies. Always read from Design HTML, never assume from another template.**

**(79) Flag pill anchor is template-specific: grid-4 is `right: 28px`, grid-3 is `left: 32px`. Verify per template — always look at the HTML before copying.**
