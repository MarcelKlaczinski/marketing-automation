# Spec 64.6 — Hero-Image Quality Bundle: Nano Banana 2 + Outline Rule Tightening

_Fixes Hero-Image Quality Problems aus Phase 1 Diagnose (2026-05-22)._
_Status: Draft._
_Aufwand: ~3-4h Implementation + ~30 Min Tests + 15 Min Adapter-Tests._
_Voraussetzung: keine direkten Abhängigkeiten — orthogonal zu Spec 64.3-64.5._

---

## 1. Problem

Phase 1 Hero-Image Diagnose (2026-05-22) hat zwei separate Quality-Issues identifiziert:

### Issue A: Outline-Rule erlaubt explizit Text-Labels

**Root Cause:** Outline-Step Prompt (`packages/pipelines/src/article/steps/outline.ts:94`, Rule 6) enthält:

> "Short text labels (1-3 words) ARE allowed when they aid comprehension — e.g. tier names on pricing cards ('Free', 'Plus', 'Pro'). Keep text under 3 words per label."

**Problem:** Sampled prompts nutzen das **heavy** — z.B. Copilot-Reviews mit 3 tier-name labels auf small pricing-cards.

**Konsequenz:** Flux 1.1 Pro (current model) **degradiert sharply bei 3+ labels in close proximity** → produziert "random pseudo-script" Symptom.

Marcel-Beobachtung 2026-05-21: "qualitativ nicht gut, oft random Schrift".

### Issue B: Flux 1.1 Pro ist suboptimaler Model für Editorial Hero-Images

**Marcel-Test 2026-05-22:** Nano Banana 2 (Gemini Flash Image, gemini-3-flash-image-preview) produziert visuell **signifikant bessere Bilder** für identischen Editorial-Prompt:
- Bessere Komposition + Brand-Konsistenz
- Sauberere Editorial-Photography-Aesthetic
- Premium-Look ohne Glossy-Stock-Art

**Cost-Vergleich (verified 2026-05-22 web-search):**

| Model | Cost pro Bild | Quality |
|---|---|---|
| Flux 1.1 Pro (current) | $0.04 | Pseudo-Schrift bei 3+ Labels |
| **Nano Banana 2 (chosen)** | **~$0.067** | Deutlich besser bei composition + brand |
| Nano Banana Pro 2K | $0.134 | Premium, overkill für Standard-Articles |

**Cost-Impact bei 50 Articles/Monat:** +€1.10/Monat (~€2 → ~€3.10). Trade-off lohnt sich.

### Issue C: Seed null = nicht reproducible

Adapter und Step akzeptieren `seed` Parameter, aber werden mit `undefined` aufgerufen — jede Generation random. Marcel kann schlechte Bilder nicht deterministisch A/B-vergleichen mit anderen Seeds.

**Quality-of-Life Issue, nicht primärer Bug.** Aber: zusammen mit Image-Model-Wechsel sinnvoll implementiert.

---

## 2. Ziel

**Drei orthogonale Fixes als Bundle:**

**Fix A (Outline Rule):** Drop "short text labels are allowed", replace mit explicit "no text labels" Rule + scene-level negative.

**Fix B (Image Model):** Nano Banana 2 als default für Toolwiki Hero-Images. Flux 1.1 Pro bleibt im Adapter-Registry für eventuelle Fallback / per-style Routing in Zukunft.

**Fix C (Reproducible Seed):** Hero-Image Step generiert seed aus `articleId` hash → re-runs sind deterministic. Plus: UI-Re-Roll-Button kann seed+1 nutzen für controlled A/B.

**In Scope:**
- Outline-Prompt Rule 6 ersetzen
- Neuer Adapter `packages/adapters/nano-banana/` für Google Gemini Image API
- Hero-Image Step (`packages/pipelines/src/article/steps/hero-image.ts`) auf Nano Banana 2 default umstellen
- Seed-Generation aus articleId in Hero-Image Step
- Adapter-Tests (mock'd Gemini API response)
- Project-Config: `signal_sources` Pattern als Vorlage — `image_generation.provider: 'nano-banana-2' | 'flux-1.1-pro'` als toggleable setting
- Cost-Tracking: cost_logs.service='gemini' (oder 'google-image') statt 'replicate'

**Out of Scope:**
- Nano Banana Pro Premium-Tier Routing (für später wenn comparison/spec articles brauchen)
- Per-Article-Type heroImageStyle enum extension (für später)
- Existing 19 R2 hero keys regenerieren (Cleanup hat sie schon weg)
- UI Re-Roll Button (Fix C ermöglicht es, UI separater PR)
- Batch-Mode für Cost-Reduction (50%-discount async, aber 24h SLA inkompatibel mit current flow)

**Aufwand:** ~3-4h.

**Nachher (Fixed):**

```
6. **Hero image**: A highly specific prompt for Nano Banana 2.
   Rules:
   - Describe a concrete scene with 1-3 physical objects. No abstract concepts.
   - Include composition (overhead flatlay / 3/4 angle / close-up), lighting
     (diffused window light / studio rim light), background (cream, dark slate,
     marble, etc.) and mood.
   - For articles about a specific product/tool (ChatGPT, Claude, Midjourney, etc.):
     reference its brand color and/or visual identity (icon shape, UI style) concretely.
   - **NO text labels of any kind.** No tier names, no brand-name lettering on cards,
     no checklist items, no annotations, no readable writing in the scene. Convey
     hierarchy/tiers/sequence via shape, color, position, or symbolic icons
     (squares, circles, arrows) — never via rendered text. If a brand identity
     requires its name visible, the brand's official logo glyph (not text) is OK.
   - AVOID: people, faces, screens showing UI text, dense paragraphs of text,
     watermarks, typography, signage, readable writing of any kind.
   - Style enum picks the rendering mode — choose what best fits the scene.
   Target: 80-200 words. Longer is better than vague.
```

**Decision-Rationale:**
- Komplette Beseitigung der "text labels are allowed" Affordance
- Plus stärkere Komposition-Hinweise auf symbolische Hierarchie (statt Text-Tier-Names)
- Plus stärkere Negative-Constraints am Ende
- Model-Reference updated von "Flux 1.1 Pro" zu "Nano Banana 2"

### 3.3 Hero-Image Step Migration (Fix B + Fix C)

**File:** `packages/pipelines/src/article/steps/hero-image.ts`

**Vorher:**

```ts
  seed: undefined,  // random every call

```

**Nachher:**

```ts
import { generateImage } from "@marketing-auto/adapter-nano-banana";
import { resolveImageProvider } from "../../lib/image-provider";  // helper für project-config

// Hash articleId zu reproducible seed
function seedFromArticleId(articleId: string): number {
  // Simple deterministic hash → 32-bit int seed
  let hash = 0;
  for (let i = 0; i < articleId.length; i++) {
    hash = ((hash << 5) - hash) + articleId.charCodeAt(i);
    hash |= 0;
  }
  return Math.abs(hash);
}

const provider = await resolveImageProvider(ctx.projectId);
// provider.model: 'nano-banana-2' (default für Toolwiki)
// provider.apiKey: from project_credentials

const result = await generateImage({
  prompt: outline.heroImagePrompt,
  model: provider.model,
  aspectRatio: "16:9",
  outputFormat: "webp",
  outputQuality: 90,
  seed: seedFromArticleId(input.articleId),
}, provider.apiKey);
```

**Plus Fallback-Branch (defensive):**

```ts
// If nano-banana provider config missing or API key invalid, fallback to replicate
// Log warn but don't block the pipeline.
if (!provider) {
  log.warn({ articleId }, "Image provider config missing — falling back to flux-1.1-pro");
  // ... existing replicate call as backup ...
}
```

**Decision:** Fallback nicht zu aggressiv — wenn API failed, retry-Logic auf Adapter-Ebene (3 attempts mit exponential backoff). Fallback zu Replicate nur wenn config komplett fehlt.

## 12. Memory-Update (Skelett — Marcel entscheidet)

Pattern eligible für Memory:
- **Nano Banana 2 als default Image-Model** (Toolwiki, Mai 2026): bessere Quality als Flux 1.1 Pro, ~1.7× Cost (~$0.067/Bild bei 2K vs $0.04). Provider-Wechsel war isoliert auf ein Migration-Pair (enum-widening + column-add) + ein neuer Adapter — kein Pipeline-Step-Rewrite. Lesson: when Marcel says "this model is better visually", a per-project provider toggle with a sensible default is faster than carving exceptions into the existing adapter.
- **Deterministic Image-Seed from articleId hash**: 31-bit positive int via `(h << 5) - h + charCode` accumulator. Same articleId → same seed → reproducible images for editorial A/B + future UI re-roll-with-seed+1. Pure helper, no state.
- **Image-Provider Config Pattern**: `projects.image_generation_provider text NOT NULL DEFAULT 'nano-banana-2'` flat column wins over JSONB versioning when the setting is a single toggleable choice with no audit history requirement. Mirrors existing toggles `llmMode` / `translationAutoTrigger` / `autoPublish`. Spec originally called for `project_configurations.image_generation` jsonb — but the table has no `config_json` column and JSONB versioning was overkill for a binary choice.
- **Schema-example drift in prompt literals** (already codified as root CLAUDE.md DO NOT): when changing any model-reference inside an inline LLM-prompt literal, grep the same string within the literal scope (`OUTLINE_STEP_DEFAULT_PROMPT` template literal) before committing — the JSON-schema example following the rules block typically restates field types with model names that drift silently from the rule text. Caught by /review-task on Spec 64.6: Rule 6 body said "Nano Banana 2" while the schema example two screenfuls below still said "Flux 1.1 Pro prompt".
