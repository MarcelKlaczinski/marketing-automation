### D.1 Three Options to Evaluate

**Option 1: Complete the DataForSEO integration**
- Pre-fetch keyword/trend data
- Feed into LLM prompt as context
- LLM picks contextually-appropriate hashtags
- Estimated effort + cost + quality gain

**Option 2: Remove DataForSEO, improve LLM-only generation**
- Delete `ResearchHashtagsStep`
- Beef up GenerateCaptionStep prompt with better hashtag instructions
- LLM uses article context + tool data + brand voice to generate hashtags
- Cheaper (no DataForSEO calls), faster pipeline, possibly equal quality?

**Option 3: Hybrid — Hashtag categories rather than research**
- Skip DataForSEO entirely
- Use a curated hashtag library per category (tool category, content type, locale)
- LLM selects + ranks from library + adds article-specific tags
- Cheapest, most deterministic, no external dependency
