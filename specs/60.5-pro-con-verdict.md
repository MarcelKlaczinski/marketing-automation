# Spec 60.5 — `pro-con-verdict` Remotion Composition

**Date:** 2026-05-19
**Theme:** 60 — Design System Migration
**Template key:** `pro-con-verdict`
**Visual source:** Claude Design HTML (4 variants: dark/light × de/en)
**Prerequisite:** 60.4 done
**Estimated effort:** ~0.75 day

---

## TL;DR

Single-slide composition for one tool. Two-column card layout (pros left, cons right), each with a colored left/right border accent and tinted background. Below both columns: a full-width verdict strip with tool icon + verdict quote + recommendation tag. Hero h1 uses `brand-300` for `.em` (back to normal after verdict-per-use-case's accent-500 exception). Glow: bottom-left, `brand-500`, alpha 25% — same as grid-3/spotlight. New Lucide icons: `CheckCircle2` and `XCircle` for column headers.

---

```

```


### A.3 Top Bar — identical to all templates

Standard `.top` / `.eyebrow` / `.num` / `.right` pattern.

### A.4 Hero

```
h1:     font-size 64px (!!), weight 700, line-height 1.05, letter-spacing -0.035em, margin 0
  .em:  color var(--brand-300)    ← brand-300, back to normal
.sub:   font-size 18px, color ink-muted, margin-top 12px (not 16/18px!),
        max-width 880px, line-height 1.45
```

**Critical:** h1 is **64px** — larger than all other templates (all others use 60px).
Sub `margin-top` is **12px** (verdict-per-use-case = 16px, others = 18px).
Sub `line-height` is **1.45** (others use 1.4).

```

grid-template-rows:    1fr auto
gap:                   18px
```

Two rows: top row = two equal columns (pros + cons), bottom row = verdict strip spanning both.

### D.2 Verdict text rendering

The verdict text contains an `.em` span. The LLM provides `verdict_text` as the
full string and `verdict_em` as the substring to highlight. Component splits at
render time:

```tsx
// Split verdict_text around verdict_em
const parts = g.verdictText.split(g.verdictEm);
// Renders: parts[0] + <span style={{color: emColor}}>{g.verdictEm}</span> + parts[1]
```

If `verdictEm` is not found in `verdictText`, render `verdictText` unsplit.
Never fail on split mismatch.

## Section E — Composition Implementation

### E.1 `ProConVerdictSlide.tsx`

```tsx
import React, { useMemo } from 'react';
import { Check, CheckCircle2, X, XCircle, Users } from 'lucide-react';
import { deriveDsTokens, resolveBrandTokens } from '../../lib/brand-tokens';
import { DsGlow } from '../../ds-components/DsGlow';
import { DsTop } from '../../ds-components/DsTop';
import { DsFoot } from '../../ds-components/DsFoot';
import { ToolIconImage } from '../../ds-components/ToolIconImage';
import type { ProConVerdictProps } from './types';

export const ProConVerdictSlide: React.FC<ProConVerdictProps> = (props) => {
  const { generated: g, brandTokens, theme } = props;

  const tokens = useMemo(
    () => deriveDsTokens(resolveBrandTokens(brandTokens), theme),
    [brandTokens, theme],
  );

  const isLight = theme === 'light';
  const emColor = isLight ? tokens.brand500 : tokens.brand300;

  // Split verdict text around em span
  const verdictParts = g.verdictText.includes(g.verdictEm)
    ? g.verdictText.split(g.verdictEm)
    : [g.verdictText, ''];

  return (
    <div
      style={{
        width: 1080,
        height: 1350,
        backgroundColor: isLight ? 'oklch(99% 0.005 250)' : tokens.surface,
        color: tokens.ink,
        fontFamily: tokens.fontSans,
        padding: 56,
        boxSizing: 'border-box',
        position: 'relative',
        overflow: 'hidden',
        display: 'grid',
        gridTemplateRows: 'auto auto 1fr auto',
        rowGap: 28,
      }}
    >
      {/* Glow — bottom-left, brand-500, alpha 25 */}
      <DsGlow tokens={tokens} corner="bottom-left" size={800} alpha={25} />

      <div style={{ position: 'relative', zIndex: 1, display: 'contents' }}>

        {/* TOP BAR */}
        <DsTop
          tokens={tokens}
          eyebrow={g.eyebrow}
          num={g.dateLabel}
          rightText={g.slideNum}
        />

        {/* HERO */}
        <div>
          <h1
            style={{
              fontSize: 64,              // ← 64px (all others = 60px)
              fontWeight: 700,
              lineHeight: 1.05,          // ← 1.05 (others = 1.08)
              letterSpacing: '-0.035em',
              margin: 0,
            }}
          >
            {g.toolName}{' '}
            <span style={{ color: emColor }}>·</span>
            <br />
            {'der '}
            <span style={{ color: emColor }}>{g.toolCategory}</span>
            {'.'}
          </h1>
          <p
            style={{
              fontSize: 18,
              color: tokens.inkMuted,
              maxWidth: 880,
              lineHeight: 1.45,          // ← 1.45 (others = 1.4)
              margin: '12px 0 0',        // ← 12px (others = 16–18px)
            }}
          >
            {g.subline}
          </p>
        </div>

        {/* VERDICT BODY */}
        <div
          style={{
            display: 'grid',
            gridTemplateColumns: '1fr 1fr',
            gridTemplateRows: '1fr auto',
            gap: 18,
          }}
        >
          {/* PROS COLUMN */}
          <div
            style={{
              backgroundColor: `color-mix(in oklab, ${tokens.accent500} 5%, ${tokens.surfaceRaised})`,
              border: `1px solid ${tokens.border}`,
              borderLeft: `4px solid ${tokens.accent500}`,   // ← left accent bar
              borderRadius: 18,
              padding: '22px 24px',
              display: 'flex',
              flexDirection: 'column',
              gap: 14,
              boxShadow: isLight ? tokens.shadow1 : 'none',
            }}
          >
            {/* Column header */}
            <div
              style={{
                display: 'flex', alignItems: 'center', gap: 10,
                fontSize: 14, letterSpacing: '0.14em',
                textTransform: 'uppercase', fontWeight: 700,
                color: tokens.accent500,
              }}
            >
              <CheckCircle2 size={18} strokeWidth={1.75} />
              {g.prosHeader}
            </div>
            {/* Items */}
            <div style={{ display: 'flex', flexDirection: 'column', gap: 12 }}>
              {g.pros.map((text, i) => (
                <div key={i} style={{ display: 'flex', gap: 10, alignItems: 'flex-start', fontSize: 15, lineHeight: 1.4, color: tokens.ink }}>
                  <div style={{ flexShrink: 0, marginTop: 3, color: tokens.accent500 }}>
                    <Check size={16} strokeWidth={1.75} />
                  </div>
                  {text}
                </div>
              ))}
            </div>
          </div>

          {/* CONS COLUMN */}
          <div
            style={{
              backgroundColor: `color-mix(in oklab, ${tokens.danger} 5%, ${tokens.surfaceRaised})`,
              border: `1px solid ${tokens.border}`,
              borderRight: `4px solid ${tokens.danger}`,     // ← right danger bar
              borderRadius: 18,
              padding: '22px 24px',
              display: 'flex',
              flexDirection: 'column',
              gap: 14,
              boxShadow: isLight ? tokens.shadow1 : 'none',
            }}
          >
            {/* Column header */}
            <div
              style={{
                display: 'flex', alignItems: 'center', gap: 10,
                fontSize: 14, letterSpacing: '0.14em',
                textTransform: 'uppercase', fontWeight: 700,
                color: tokens.danger,
              }}
            >
              <XCircle size={18} strokeWidth={1.75} />
              {g.consHeader}
            </div>
            {/* Items */}
            <div style={{ display: 'flex', flexDirection: 'column', gap: 12 }}>
              {g.cons.map((text, i) => (
                <div key={i} style={{ display: 'flex', gap: 10, alignItems: 'flex-start', fontSize: 15, lineHeight: 1.4, color: tokens.ink }}>
                  <div style={{ flexShrink: 0, marginTop: 3, color: tokens.danger }}>
                    <X size={16} strokeWidth={1.75} />
                  </div>
                  {text}
                </div>
              ))}
            </div>
          </div>

          {/* VERDICT STRIP — spans both columns */}
          <div
            style={{
              gridColumn: '1 / -1',
              backgroundColor: tokens.surfaceRaised,
              border: `1px solid color-mix(in oklab, ${tokens.brand500} 40%, ${tokens.border})`,
              boxShadow: isLight
                ? tokens.shadow2
                : `0 0 40px -16px color-mix(in oklab, ${tokens.brand500} 45%, transparent)`,
              borderRadius: 20,
              padding: '22px 26px',
              display: 'grid',
              gridTemplateColumns: '56px 1fr',
              columnGap: 18,
              rowGap: 8,
              alignItems: 'center',
            }}
          >
            {/* Tool icon — spans both rows */}
            <div style={{ gridRow: '1 / span 2' }}>
              <ToolIconImage
                iconSvg={g.iconSvg}
                iconInitials={g.iconInitials}
                iconHue={g.iconHue}
                size={56}
                borderRadius={14}
              />
            </div>

            {/* Verdict text with em span */}
            <div
              style={{
                fontSize: 20,
                fontWeight: 600,
                lineHeight: 1.3,
                letterSpacing: '-0.015em',
                color: tokens.ink,
              }}
            >
              "{verdictParts[0]}
              {verdictParts[1] !== undefined && (
                <span style={{ color: emColor }}>{g.verdictEm}</span>
              )}
              {verdictParts[1]}"
            </div>

            {/* Recommendation tag */}
            <div
              style={{
                display: 'inline-flex',
                alignItems: 'center',
                gap: 6,
                padding: '5px 12px',
                borderRadius: 999,
                background: `color-mix(in oklab, ${tokens.brand500} 14%, transparent)`,
                border: `1px solid color-mix(in oklab, ${tokens.brand500} 35%, transparent)`,
                fontFamily: tokens.fontMono,
                fontSize: 12,
                fontWeight: 600,
                color: emColor,
                width: 'fit-content',
              }}
            >
              <Users size={12} strokeWidth={1.75} />
              {g.recommendationTag}
            </div>
          </div>
        </div>

        {/* FOOTER */}
        <DsFoot
          tokens={tokens}
          ctaBold={g.ctaLine1}
          ctaLead={g.ctaLine2}
        />
      </div>
    </div>
  );
};
```

## Section L — DS Component Notes

### L.1 `DsGlow`

`corner="bottom-left" alpha={25}` — standard, no new props needed.

### L.2 New Lucide icons

`CheckCircle2` and `XCircle` used in column headers (18px).
`Users` used in recommendation tag (12px).
All three are new to this template — verify available in `lucide-react@0.383.0`.

### L.3 Dual border handling

The pros column has `border: 1px solid border` + `borderLeft: 4px solid accent500`.
In Remotion inline styles, setting `borderLeft` after `border` correctly overrides
just the left side. Do not use `borderWidth` shorthand — it resets all sides.

### L.4 `fit-content` on vtag

`width: 'fit-content'` in inline styles is supported in Remotion's Chromium renderer.
Do not replace with a flex wrapper — the HTML explicitly uses `fit-content`.

### L.5 Light mode `.em` color

In light mode: hero h1 `.em` AND verdict strip `.em` both use `tokens.brand500`
(not `brand300`). This is the only template with this light-mode em color swap.
Controlled by `emColor` variable: `isLight ? tokens.brand500 : tokens.brand300`.

## Section P — Patterns Established by 60.5

**(92) `pro-con-verdict` h1 is 64px (not 60px). Template-specific font sizes must always be read from HTML — never assume 60px across templates.**

**(93) Dual border in Remotion: set `border` first, then override one side with `borderLeft` or `borderRight`. This works correctly in Chromium inline styles. Never use `borderWidth` array shorthand.**

**(94) Verdict text em-split pattern: LLM provides `verdict_text` (full) + `verdict_em` (substring). Component splits with `.split(verdictEm)`. Always guard against split mismatch — if substring not found, render unsplit. Never fail on missing em.**

**(95) Light mode `emColor` variable: `isLight ? tokens.brand500 : tokens.brand300`. Pro-con-verdict is the only template needing this swap for both hero h1 AND verdict strip simultaneously. Use a single `emColor` variable, not two separate conditions.**
