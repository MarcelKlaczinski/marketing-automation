## 3. Architecture Decisions

### 3.1 Design-System: 3 Signature Visual-Languages

**Per Marcel niche-analysis, 3 color-languages "die siegen, nie gemixt":**

#### Preset 1: Dark Neon Grid (aditya-style)

```
Aesthetic: Cinematic dark, electric energy, tech-magic
Colors:
  - Base: near-black (#0A0A0F) to deep-purple (#1A0B2E)
  - Accent: electric-blue (#00D4FF) + neon-purple (#B14EFF)
  - Highlight: hot-magenta (#FF2E97) sparingly
Typography:
  - Display: bold geometric sans (e.g. "Clash Display", "Druk", NOT Inter)
  - Body: clean mono OR refined sans (e.g. "Space Mono" für tech-coded)
Texture:
  - Subtle grid-overlay (perspective lines, vanishing-point)
  - Glow/bloom on accent elements
  - Grain overlay for cinematic depth
NB2-prompt-direction:
  - "cinematic dark tech scene, electric blue and purple neon lighting,
     volumetric glow, deep shadows, futuristic, high-contrast,
     NOT flat, NOT stock-photo, editorial-grade composition with negative-space
     for text-overlay in lower-third"
Best for: story-arc (drama), opinion (hot-take energy)
```

#### Preset 2: Light Editorial (Kinfolk/Monocle-style)

```
Aesthetic: Refined magazine, premium, calm-confident
Colors:
  - Base: warm cream (#F7F3ED) to off-white (#FAFAF8)
  - Text: rich near-black (#1A1A1A) + warm-charcoal
  - Accent: single bold color per carousel (terracotta #C8553D OR forest #2D4A3E)
Typography:
  - Display: distinctive serif (e.g. "Fraunces", "Canela", editorial-grade)
  - Body: refined humanist sans (e.g. "Söhne", NOT Inter)
Texture:
  - Generous negative-space
  - Subtle paper-grain
  - Thin editorial rules/borders
NB2-prompt-direction:
  - "refined editorial photography style, warm natural light, minimalist
     premium composition, Kinfolk magazine aesthetic, muted warm tones,
     single subject, abundant negative-space, NOT stock-photo, NOT busy"
Best for: lifestyle-listicle (premium-calm), educational content
```

#### Preset 3: Blue Tech Gradient (bold energetic)

```
Aesthetic: Modern SaaS-energy, optimistic-tech, accessible
Colors:
  - Base: gradient blue (#0066FF → #00C2FF) OR (#1E3A8A → #3B82F6)
  - Accent: bright-white + cyan-pop (#00F0FF)
  - Highlight: warm contrast (#FFB800 amber)
Typography:
  - Display: bold modern sans (e.g. "Cabinet Grotesk", "General Sans")
  - Body: clean geometric (e.g. "Satoshi")
Texture:
  - Smooth gradient mesh
  - Subtle geometric shapes (circles, soft-blobs)
  - Light glow on key elements
NB2-prompt-direction:
  - "modern tech illustration, bold blue gradient background, clean
     energetic composition, optimistic SaaS aesthetic, geometric accents,
     bright and accessible, NOT dark, NOT cliché-purple-gradient,
     professional with text-space"
Best for: head-to-head, top-n-comparison (Family-A future), accessible-tech
```

### Discovery-Recommendation: **3 presets as design-tokens + NB2-prompt-templates, NOT hardcoded per-format**

Reasoning:

1. **Marcel chose content-level-selectable** — presets are options, not format-bound
2. **Each preset = complete design-language** (color + typography + texture + NB2-prompt + DS-token-override)
3. **Design-skill enforced** — distinctive fonts, dominant-colors, atmosphere, explicit anti-AI-slop
4. **Reusable für BK Solar** — they'd define own presets (e.g. "warm-solar-gold")
5. **Anti-generic by construction** — each preset has signature texture + non-Inter typography

**CRITICAL design-skill note:** These 3 are STARTING templates. Per skill "never converge on common choices" — the NB2-prompts must produce VARIED output within each preset, not identical-looking slides. Seed-variation + prompt-diversity within preset.

function resolveImageProvider(formatType, contentLevelChoice, project): 'nano-banana-2' | 'photographic' {

### 3.5 NB2 Signature-Prompt Engineering

**Per slide-context (Cover vs body) + preset + narrative-beat:**

```typescript
// packages/social/src/presets/nb2-prompts.ts

function buildNB2Prompt(input: {
  preset: PresetKey;
  slideRole: 'cover' | 'conflict' | 'resolution' | 'payoff' | 'item' | 'hot-take' | 'top-pick';
  narrativeBeat: string;      // LLM-generated beat-text for context
  hookContext: HookContext;
  brandPrimaryColor: string;
}): { prompt: string; negativePrompt: string } {
  
  const presetStyle = PRESET_STYLE_DIRECTIONS[input.preset];
  
  // Slide-role determines composition focus:
  const roleComposition = {
    cover: 'bold hero composition, strong focal point, negative-space lower-third for headline',
    conflict: 'tension and contrast, dramatic lighting, emotional weight',
    resolution: 'breakthrough moment, brightening, hope, forward-momentum',
    payoff: 'success and transformation, confident, aspirational',
    // ...
  }[input.slideRole];
  
  const prompt = `
${presetStyle.baseDirection}
Scene context: ${input.narrativeBeat}
Composition: ${roleComposition}
${presetStyle.textureDirection}
Aspect: vertical 4:5, editorial-grade quality
Text-overlay-ready: clear negative-space for caption
  `.trim();
  
  const negativePrompt = `
stock-photo, generic AI imagery, purple-gradient-on-white, 
flat lighting, busy composition, watermark, text, logo,
cliché tech imagery, ${presetStyle.avoid}
  `.trim();
  
  return { prompt, negativePrompt };
}
```

**CRITICAL per design-skill:** Negative-prompt explicitly bans "generic AI imagery", "stock-photo", "purple-gradient-on-white" (the named AI-slop anti-pattern). Each preset adds its own `avoid` list (e.g. dark-neon avoids "pastel/soft"; editorial avoids "neon/harsh").

**Seed-variation:** Per 65.8 Adapter-shape, NB2 returns seed. For diversity-within-preset, vary seed per slide (no two slides identical-feeling).

### 3.8 Cost + Render-Time Impact

**Per Marcel niche-analysis:** €0.07/image × 4-7 images = €0.30-0.50/carousel (NB2) vs €0.04 (stock-vision-pick).

**Cost-breakdown per NB2 Family-B carousel (4 images):**

| Cost-Source | Amount |
|---|---|
| Narrative LLM (Sonnet, 1 call) | ~€0.05 |
| 4× NB2 image-gen | ~€0.28 |
| R2 stage (covered by adapter) | ~€0.001 |
| **Total NB2 carousel** | **~€0.33** |

vs photographic ~€0.20-0.25. **+€0.10/carousel for signature-quality.** Within Marcel's quality>price budget (€0.30-0.50 acceptable per earlier decisions).

**Budget-integration:** recurring_content_total budget (V1.5b, €15/month default) covers ~45 NB2-carousels/month. Fine for V1.

**Render-time:** NB2 gen ~5-10s per image (Gemini), 4 parallel ~15-20s. vs photographic ~30s (search+vision-pick). **NB2 might be FASTER** (no multi-provider-search + vision-pick roundtrip). Verify §2.1 Q5.

## 11.5 V1.7 Implementation Log

Follow-ups landed across two same-day commits:

### V1.7 #1 — Slide-component preset DS-token reads (commit `0242911`)

**Closes the gap** where the NB2-generated image carried the active preset's signature visual language but the text overlay on top kept reading generic tokens.

**Mechanism — legacy-slot aliasing** (the pattern surfaced during implementation, documented in `packages/social/CLAUDE.md`):
- `derivePresetEmotionalDsTokens` was extended to alias preset values into the LEGACY token slots that slide components already read (`tokens.typography.fontFamily` → preset display font, `tokens.accent[500]` → preset textAccent, `tokens.ink.base` → preset textPrimary, `tokens.typography.eyebrowLetterSpacing` → preset eyebrow letter-spacing).
- New `deriveTokensForRender(brandTokens, theme, preset?)` is a slide-component-friendly union-returning wrapper — returns `EmotionalDsTokens` when no preset is set (back-compat), `PresetEmotionalDsTokens` when set. `hasPresetTokens(tokens)` is the discriminator type-guard.
- Result: **no per-slide branching needed**. Slides keep their existing `tokens.typography.fontFamily` / `tokens.accent[500]` reads. The 14 slide files just swap `deriveEmotionalDsTokens` → `deriveTokensForRender` + thread a `preset?: PresetKey | null` prop.

**Surfaces touched** (17 files, ~4 lines each):
- 14 slide components — import swap + preset prop + useMemo deriver call + deps array
- 3 dispatcher composition files (`StoryArcClickbait.tsx` / `LifestyleListicle.tsx` / `OpinionRecommendation.tsx`) — destructure `preset` from `props` + conditional-spread `...(preset !== undefined && { preset })` to each child
- 1 shared `RenderEndSlide.tsx` — accept `preset` prop, forward to inline-end-slide via the same conditional spread

**Fan-out via transform script:** the 11 remaining slide files after the first hand-crafted CoverSlide.tsx edit were batched through a 30-line bun script doing 5 regex transforms (`/tmp/spec-65.16-preset-fan-out.ts`, ephemeral). Each file ran 5 deterministic substitutions — no manual review per file. Output: 11/11 `✓` with the script exiting non-zero on any "NO CHANGES applied" sentinel.

**Tests:** 10 new in `packages/social/test/presets/preset-ds-tokens.test.ts` confirming the legacy-slot aliasing contract — preset values land in `tokens.accent[500]` / `tokens.typography.fontFamily` / `tokens.ink.base` etc., not just `tokens.preset.*`. The "fonts are distinct across 3 presets" sanity check proves preset typography actually flows through the legacy slot.

**Closes the half-shipped UX feel** where backend already accepted `socialImageStylePresetOverride` (V1.6 migration 0130) but the field had no INSERT plumbing and no UI surface.
