## 1. Problem

Discovery 64.8 hat **drei nicht-blockierende Findings** identifiziert die zusammen gefixt werden sollen:

### Finding A: Resolution-Toggle ist No-Op

> "Gemini Image API derives aspect-ratio + resolution from the **prompt text alone**." (Discovery §4)

Migration 0089 (64.6b) hat `projects.image_generation_resolution` column eingeführt für 4 resolutions ('0.5k', '1k', '2k', '4k'). **Aber:** Gemini API hat keinen API-Parameter dafür. Resolution kommt aus prompt-text-injection (z.B. `"…16:9 widescreen, 1K resolution"`).

**Marcel-Decision (2026-05-22):** Column behalten + prompt-injection nutzen.

### Finding B: Audit-Trail-Gap im cost_logs

> "The actual prompt text used at generation time is **not recoverable** from the DB." (Discovery §1)

`cost_logs.metadata` speichert aktuell:
- model, predictionId, durationMs, bytesStored, articleId, seed

Fehlt für Quality-Audits:
- **Prompt text** (kritisch — Hauptproblem in Discovery)
- augment-step Info (für Spec 64.8 future)
- Plus: resolution, aspectRatio (was tatsächlich gerendered wurde)

### Finding C: Keine Fresh Nano Banana Samples

Toolwiki hat **0 erfolgreiche Nano Banana generations** (alle predate 64.6 / sind Flux 1.1 Pro). Spec 64.8 (Post-Draft Refactor) braucht fresh samples für decision ob outline-rule + Nano Banana 2 ausreichen ODER ob Post-Draft Refactor nötig ist.

**Marcel-Decision:** 3-5 fresh samples nach 64.6c deploy generieren (~€0.20-0.40 cost).

**Fix A: Resolution Prompt-Injection** — HeroImageStep liest `projects.image_generation_resolution`, injiziert entsprechenden hint in den prompt text vor adapter-call.

## 3. Architektur

### 3.1 Resolution Prompt-Injection (Fix A)

**File:** `packages/pipelines/src/article/steps/hero-image.ts`

**Pattern:** vor adapter-call wird der prompt augmentiert mit resolution-hint + aspect-ratio.

**Code Skeleton:**

```ts
// packages/pipelines/src/article/lib/prompt-resolution-hints.ts (neu)

import type { NanoBananaResolution } from "@marketing-auto/adapter-nano-banana";

const RESOLUTION_HINTS: Record<NanoBananaResolution, string> = {
  "0.5k": "low-resolution preview quality, 512px",
  "1k": "1K resolution, standard editorial photography quality, 1024px",
  "2k": "2K high-resolution editorial photography, 2048px",
  "4k": "4K resolution, premium print quality, 4096px",
};

const ASPECT_HINT = "16:9 widescreen aspect ratio";

/**
 * Augment hero-image prompt with resolution + aspect hints.
 * 
 * Gemini Image API derives output dimensions from prompt text (Discovery 64.8 §4).
 * This helper injects explicit hints to override Gemini's default square crop.
 */
export function buildPromptWithResolutionHint(
  basePrompt: string,
  resolution: NanoBananaResolution,
): string {
  const resolutionHint = RESOLUTION_HINTS[resolution];
  return `${basePrompt.trim()}\n\nFormat: ${ASPECT_HINT}, ${resolutionHint}.`;
}
```

**HeroImageStep Patch:**

```ts
// In execute(), nach config-resolve + vor adapter-call:
const augmentedPrompt = buildPromptWithResolutionHint(
  outline.heroImagePrompt,
  config.resolution,
);

const result = await generateImage({
  prompt: augmentedPrompt,        // <-- statt outline.heroImagePrompt verbatim
  model: config.model,
  aspectRatio: "16:9",
  resolution: config.resolution,
  outputFormat: "webp",
  seed: seedFromArticleId(article.id),
}, apiKey);
```

**Backwards Compat:** existing tests die `outline.heroImagePrompt` verbatim assertieren werden brechen — Tests müssen aktualisiert werden auf augmented prompt assertions.

### 3.3 Sample Re-Bake Script (Fix C)

**File:** `apps/api/src/scripts/rebake-hero-samples.ts` (neu)

**Usage:**

```bash
bun --filter @marketing-auto/api rebake-hero-samples \
  --project toolwiki \
  --count 5 \
  --collections blog,comparisons,ki-wissen \
  --dry-run  # optional: preview ohne adapter-call
```

**Code Skeleton:**

```ts
import { db } from "@marketing-auto/db";
import { generateImage } from "@marketing-auto/adapter-nano-banana";
import { resolveImageProvider } from "../lib/image-provider";
import { buildPromptWithResolutionHint } from "@marketing-auto/pipelines/article/lib/prompt-resolution-hints";

interface ReBakeOptions {
  projectSlug: string;
  count: number;
  collections?: string[];
  dryRun?: boolean;
}

async function rebakeHeroSamples(opts: ReBakeOptions) {
  const project = await getProjectBySlug(opts.projectSlug);
  
  // Select diverse sample articles
  const articles = await db.query.articles.findMany({
    where: and(
      eq(articles.projectId, project.id),
      eq(articles.source, "imported"),
      opts.collections ? inArray(articles.collection, opts.collections) : sql`true`,
    ),
    orderBy: [sql`RANDOM()`],
    limit: opts.count * 3,  // sample 3x, dedupe by collection
  });
  
  // Diversify by collection
  const diversified = pickDiverseByCollection(articles, opts.count);
  
  log.info({ count: diversified.length, slugs: diversified.map(a => a.slug) },
    "rebaking hero samples");
  
  const provider = await resolveImageProvider(project.id);
  const config = await resolveImageConfig(project.id);
  
  for (const article of diversified) {
    // Re-construct heroImagePrompt from article.outline (fallback: title + cluster)
    const heroPrompt = article.outline?.heroImagePrompt 
      ?? buildFallbackHeroPrompt(article);
    
    const augmentedPrompt = buildPromptWithResolutionHint(heroPrompt, config.resolution);
    
    if (opts.dryRun) {
      log.info({ slug: article.slug, prompt: augmentedPrompt }, "DRY RUN — would call adapter");
      continue;
    }
    
    try {
      const result = await generateImage({
        prompt: augmentedPrompt,
        model: provider.model,
        aspectRatio: "16:9",
        resolution: config.resolution,
        outputFormat: "webp",
        seed: seedFromArticleId(article.id),
      }, provider.apiKey);
      
      log.info({ 
        slug: article.slug, 
        url: result.publicUrl, 
        costEur: result.costEur,
        durationMs: result.durationMs,
      }, "sample baked");
    } catch (err) {
      log.error({ slug: article.slug, err }, "rebake failed");
    }
  }
  
  log.info("rebake complete — visit dashboard to review images");
}

function buildFallbackHeroPrompt(article: typeof articlesTable.$inferSelect): string {
  // Discovery 64.8: imported articles have outline=NULL
  // Fallback: synthesize prompt from title + collection
  return `Editorial flatlay related to "${article.title}". 
Subject: ${article.collection} content. 
Style: clean editorial photography, cream linen background, soft studio lighting. 
NO text labels of any kind. Focus on physical objects that evoke the topic.`;
}

function pickDiverseByCollection(
  articles: Article[],
  targetCount: number,
): Article[] {
  // Group by collection, pick 1 from each until targetCount
  const byCollection = groupBy(articles, a => a.collection);
  const result: Article[] = [];
  
  let added = true;
  while (added && result.length < targetCount) {
    added = false;
    for (const collection of Object.keys(byCollection)) {
      const pool = byCollection[collection].filter(a => !result.includes(a));
      if (pool.length > 0) {
        result.push(pool[0]);
        added = true;
        if (result.length >= targetCount) break;
      }
    }
  }
  
  return result;
}

// CLI parsing
const opts = parseArgs(Bun.argv);
await rebakeHeroSamples(opts);
process.exit(0);
```

## 7. Risiken

| Risk | Mitigation |
|---|---|
| Request-shape noch nicht gefixt → re-bake script wirft HTTP 400 | Phase 0 verifiziert; falls broken: separater Mini-Fix vor 64.6d |
| Prompt-injection führt zu Gemini ignoring hint | Tests verify hint-presence; live sample-rebake validates effect |
| Long prompts (500+ chars) hit Gemini context-length | 200-500 chars realistic; Gemini context >32k, kein Issue |
| cost_logs.metadata growth → DB-Bloat | Prompt strings ~500 chars × 50/Monat = 25 KB/Monat. Negligible. |
| Re-bake script picks Authors collection (no hero) → fails | Script filtert auf collections-arg; default excludes 'authors' |
| Article.outline=NULL fallback prompt is too generic | Marcel reviews samples; if fallback samples are C-tier, defer Spec 64.8 decision |
| Existing replicate adapter tests break wegen metadata-Erweiterung | metadata is JSONB-additive, optional fields; tests assert exact-match → ggf updaten |
| Resolution hint conflicts mit prompt content (e.g. prompt sagt "close-up portrait" but hint sagt "16:9 widescreen") | Marcel-Decision in Discovery: 16:9 ist consistent default. Wenn portrait-mode später nötig: per-article-type override (eigene Spec). |
