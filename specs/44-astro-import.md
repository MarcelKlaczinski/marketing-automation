## Context

The Marketing-Tool currently follows **Modell C** (DB → Astro-Repo, push-only). Articles are generated by the pipeline, stored in the DB, and pushed to the Astro repo via `astro-sync`.

This spec adds **the reverse direction**: importing existing articles from the Astro repo into the DB. This enables:

1. **Cluster-Generation context** (later in Spec 46): when the pipeline plans new clusters, it knows what already exists in the repo, avoiding duplicates and enabling smart internal-linking.
2. **Continuous mirror**: when Marcel manually edits tools, authors, or other read-only collections in the repo, the Marketing-Tool sees those changes on next re-sync.
3. **Cross-Project article visibility**: a unified `articles` table with `source` discriminator lets the UI show generated and imported articles together.
4. **Multi-language pairing**: articles with the same `translationKey` are linked as DE/EN pairs in the UI.

The model:

```
DB articles ←─────────── Astro Repo
            (RepoImportPipeline, this spec)

DB articles ─────────→ Astro Repo
            (existing astro-sync, Spec 21)
```

These two pipelines share the GitHub-App authentication and schema-resolution helpers in `packages/adapters/astro-sync/`.

## Goal

After this spec:
- **DB**: `articles` table extended with `source`, `collection`, `locale`, `translationKey`, `filePath`, `gitSha`, structured frontmatter columns, and catch-all jsonb fields. Unique constraint on `(projectId, source, collection, locale, slug)`.
- **Worker**: New `RepoImportPipeline` in `astro-sync` package mirrors all `.mdx` files from the project's Astro repo into the DB. Idempotent (gitSha-based change detection).
- **API**: New endpoints to trigger import, list imported articles per collection, and fetch translation pair details.
- **UI**: `ArticlesPage.vue` extended with top-level tabs `Generated` / `Imported`. Imported tab has sub-tabs per collection, each showing a translation-pair-grouped table with collection-specific columns. Detail view shows DE+EN side-by-side.

## Non-Goals

- **Re-import scheduling** — only manual trigger (button) and webhook are provided. Cron-based scheduling is a future spec.
- **Edit/push-back of imported articles** — all imported articles are read-only in this spec. Editing stays in the Astro repo. (Future spec can extend Spec 21 to push-back manual edits.)
- **Embedding regeneration on import** — imported articles get NULL embeddings. Spec 24 (internal-linking) can backfill embeddings later.
- **Cold-start integration** — extracting brand voice from imported articles is a separate spec (Spec 14.5 or similar).
- **Article-version history for imports** — `articleVersions` table stays unused for imports. Each re-import overwrites in place.
- **Conflict resolution UI for generated-vs-imported same slug** — both rows can coexist (different `source`); explicit conflict-resolution is future work.
- **Image/asset import** — only MDX content is imported. Images stay in the Astro repo (referenced by relative paths in body).
- **Tools-collection editing in Marketing-Tool** — Tools, Authors, Tool-Categories, Special-Landings are imported and read-only.

### Section B — Frontmatter Parser Helper

**File**: `packages/adapters/astro-sync/src/import/parse-frontmatter.ts` (new)

```typescript
import matter from "gray-matter";
import { z } from "zod";

const FrontmatterSchema = z
  .object({
    title: z.string().optional(),
    description: z.string().optional(),
    slug: z.string().optional(),
    locale: z.string().optional(),
    translationKey: z.string().optional(),
    publishedAt: z.union([z.string(), z.date()]).optional(),
    updatedAt: z.union([z.string(), z.date()]).optional(),
    author: z.string().optional(),
    category: z.string().optional(),
    subcategory: z.string().optional(),
    tags: z.array(z.string()).optional(),
    noindex: z.boolean().optional(),
  })
  .passthrough(); // Keep all other fields in extras

export type ParsedFrontmatter = z.infer<typeof FrontmatterSchema>;

export type ParseResult = {
  filePath: string;
  frontmatter: ParsedFrontmatter;
  body: string;
  // Fields extracted into typed columns:
  typed: {
    title: string | null;
    description: string | null;
    slug: string;
    locale: string | null;
    translationKey: string | null;
    publishedAt: Date | null;
    updatedAt: Date | null;
    author: string | null;
    category: string | null;
    subcategory: string | null;
    tags: string[];
    noindex: boolean;
  };
  // Everything else goes here:
  extras: Record<string, unknown>;
  // Computed:
  metadata: {
    wordCount: number;
    readingTimeMinutes: number;
    headings: Array<{ level: number; text: string }>;
    hasAffiliateLinks: boolean;
    imageCount: number;
    internalLinks: string[];
  };
};

const TYPED_FIELDS = new Set([
  "title", "description", "slug", "locale", "translationKey",
  "publishedAt", "updatedAt", "author", "category", "subcategory",
  "tags", "noindex",
]);

export function parseMdxContent(filePath: string, raw: string): ParseResult {
  const parsed = matter(raw);
  const fm = FrontmatterSchema.parse(parsed.data);
  const body = parsed.content;

  // Slug: from frontmatter, fallback to filename
  const filenameSlug = filePath.match(/([^/]+)\.mdx?$/)?.[1] ?? "";
  const slug = fm.slug ?? filenameSlug;

  // Locale: from frontmatter, fallback to path-derived (de/ or en/ in path)
  let locale: string | null = fm.locale ?? null;
  if (!locale) {
    const pathLocale = filePath.match(/\/(de|en)\//)?.[1];
    if (pathLocale) locale = pathLocale;
  }

  // Dates parsing
  const publishedAt = fm.publishedAt ? toDate(fm.publishedAt) : null;
  const updatedAt = fm.updatedAt ? toDate(fm.updatedAt) : null;

  // Extras: everything not in TYPED_FIELDS
  const extras: Record<string, unknown> = {};
  for (const [k, v] of Object.entries(parsed.data)) {
    if (!TYPED_FIELDS.has(k)) extras[k] = v;
  }

  // Compute metadata from body
  const metadata = computeBodyMetadata(body);

  return {
    filePath,
    frontmatter: fm,
    body,
    typed: {
      title: fm.title ?? null,
      description: fm.description ?? null,
      slug,
      locale,
      translationKey: fm.translationKey ?? null,
      publishedAt,
      updatedAt,
      author: fm.author ?? null,
      category: fm.category ?? null,
      subcategory: fm.subcategory ?? null,
      tags: fm.tags ?? [],
      noindex: fm.noindex ?? false,
    },
    extras,
    metadata,
  };
}

function toDate(v: string | Date): Date | null {
  if (v instanceof Date) return v;
  const parsed = new Date(v);
  return isNaN(parsed.getTime()) ? null : parsed;
}

function computeBodyMetadata(body: string) {
  // Word count (rough — strips MDX/Markdown syntax)
  const plain = body
    .replace(/```[\s\S]*?```/g, "") // code blocks
    .replace(/<[^>]+>/g, "")        // HTML/JSX tags
    .replace(/!\[.*?\]\(.*?\)/g, "")// images
    .replace(/\[.*?\]\(.*?\)/g, "") // links
    .replace(/[*_`#>]/g, "");       // markdown chars
  const words = plain.split(/\s+/).filter(Boolean);
  const wordCount = words.length;
  const readingTimeMinutes = Math.max(1, Math.round(wordCount / 200));

  // Headings (## or ### in body)
  const headings: Array<{ level: number; text: string }> = [];
  const headingRegex = /^(#{1,6})\s+(.+)$/gm;
  let match: RegExpExecArray | null;
  while ((match = headingRegex.exec(body)) !== null) {
    headings.push({
      level: match[1]!.length,
      text: match[2]!.trim(),
    });
  }

  // Affiliate detection
  const hasAffiliateLinks =
    /<AffiliateLink\b/.test(body) ||
    /<AffiliateCta\b/.test(body) ||
    /\]\(\/go\//.test(body);

  // Image count (markdown images + JSX <Image/> tags)
  const imageCount =
    (body.match(/!\[[^\]]*\]\(/g)?.length ?? 0) +
    (body.match(/<(?:Image|img)\b/g)?.length ?? 0);

  // Internal links (matched against /<de|en>/path or /go/slug/)
  const internalLinks: string[] = [];
  const linkRegex = /\]\((\/(?:de|en|go)\/[^)\s]+)\)/g;
  let lm: RegExpExecArray | null;
  while ((lm = linkRegex.exec(body)) !== null) {
    internalLinks.push(lm[1]!);
  }

  return {
    wordCount,
    readingTimeMinutes,
    headings,
    hasAffiliateLinks,
    imageCount,
    internalLinks,
  };
}
```

**Step 1: ListContentFilesStep**

Uses GitHub Tree API (recursive) to list all `.mdx` and `.md` files under `contentRoot`.

```typescript
// packages/adapters/astro-sync/src/import/steps/list-content-files.ts
import { BaseStep, type StepContext } from "@marketing-auto/pipelines/engine";
import { z } from "zod";
import { getInstallationOctokit } from "../../github-auth.ts";
import { type AstroRepoConfig, AstroRepoConfigSchema } from "../../types.ts";

const InputSchema = z.object({
  astroRepo: AstroRepoConfigSchema,
});

const OutputSchema = z.object({
  headCommitSha: z.string(),
  files: z.array(
    z.object({
      path: z.string(),
      sha: z.string(),
      size: z.number(),
    })
  ),
});

export class ListContentFilesStep extends BaseStep<
  z.infer<typeof InputSchema>,
  z.infer<typeof OutputSchema>
> {
  readonly name = "list-content-files";
  readonly inputSchema = InputSchema;
  readonly outputSchema = OutputSchema as z.ZodType<z.infer<typeof OutputSchema>>;

  override estimatedCostEur(): number { return 0; }

  async execute(input: z.infer<typeof InputSchema>, _ctx: StepContext) {
    const repo = input.astroRepo as AstroRepoConfig;
    const octokit = await getInstallationOctokit(repo.installationId);

    // Get current head SHA of default branch
    const refRes = await octokit.request(
      "GET /repos/{owner}/{repo}/git/refs/heads/{branch}",
      { owner: repo.owner, repo: repo.name, branch: repo.defaultBranch }
    );
    const headCommitSha = refRes.data.object.sha;

    // Get tree (recursive)
    const treeRes = await octokit.request(
      "GET /repos/{owner}/{repo}/git/trees/{tree_sha}",
      { owner: repo.owner, repo: repo.name, tree_sha: headCommitSha, recursive: "1" }
    );

    const contentPathPrefix = repo.contentRoot.replace(/^\/|\/$/g, "");
    const files = (treeRes.data.tree ?? [])
      .filter((entry) =>
        entry.type === "blob" &&
        entry.path?.startsWith(contentPathPrefix) &&
        /\.mdx?$/i.test(entry.path)
      )
      .map((entry) => ({
        path: entry.path!,
        sha: entry.sha!,
        size: entry.size ?? 0,
      }));

    return { headCommitSha, files };
  }
}
```

**Step 2: FilterChangedFilesStep**

Compares file `sha` (git blob SHA) against existing DB records. Skips files that haven't changed.

```typescript
// packages/adapters/astro-sync/src/import/steps/filter-changed-files.ts
import { articles, db } from "@marketing-auto/db";
import { BaseStep, type StepContext } from "@marketing-auto/pipelines/engine";
import { and, eq } from "drizzle-orm";
import { z } from "zod";

const InputSchema = z.object({
  projectId: z.string().uuid(),
  files: z.array(z.object({ path: z.string(), sha: z.string(), size: z.number() })),
});

const OutputSchema = z.object({
  changed: z.array(z.object({ path: z.string(), sha: z.string(), size: z.number() })),
  unchangedCount: z.number(),
  removedPaths: z.array(z.string()),
});

export class FilterChangedFilesStep extends BaseStep<
  z.infer<typeof InputSchema>,
  z.infer<typeof OutputSchema>
> {
  readonly name = "filter-changed-files";
  readonly inputSchema = InputSchema;
  readonly outputSchema = OutputSchema;

  override estimatedCostEur(): number { return 0; }

  async execute(input: z.infer<typeof InputSchema>, _ctx: StepContext) {
    // Load all imported articles for this project
    const existing = await db
      .select({
        filePath: articles.filePath,
        gitSha: articles.gitSha,
        id: articles.id,
      })
      .from(articles)
      .where(and(eq(articles.projectId, input.projectId), eq(articles.source, "imported")));

    const existingByPath = new Map(existing.map((a) => [a.filePath ?? "", a]));
    const incomingPaths = new Set(input.files.map((f) => f.path));

    const changed: typeof input.files = [];
    let unchangedCount = 0;

    for (const file of input.files) {
      const existing = existingByPath.get(file.path);
      if (!existing || existing.gitSha !== file.sha) {
        changed.push(file);
      } else {
        unchangedCount += 1;
      }
    }

    // Detect removed files (in DB but not in current tree)
    const removedPaths: string[] = [];
    for (const [path] of existingByPath) {
      if (!incomingPaths.has(path)) removedPaths.push(path);
    }

    return { changed, unchangedCount, removedPaths };
  }
}
```

```typescript
  parsed: z.array(
    z.object({
      filePath: z.string(),
      gitSha: z.string(),
      collection: z.string(),
      typed: z.record(z.unknown()),
      extras: z.record(z.unknown()),
      metadata: z.record(z.unknown()),
      body: z.string(),
    })
  ),
  failedCount: z.number(),
});

export class ParseFrontmatterBatchStep extends BaseStep<
  z.infer<typeof InputSchema>,
  z.infer<typeof OutputSchema>
> {
  readonly name = "parse-frontmatter-batch";
  readonly inputSchema = InputSchema;
  readonly outputSchema = OutputSchema as z.ZodType<z.infer<typeof OutputSchema>>;

  override estimatedCostEur(): number { return 0; }

  async execute(input: z.infer<typeof InputSchema>, _ctx: StepContext) {
    const repo = input.astroRepo as AstroRepoConfig;
    const octokit = await getInstallationOctokit(repo.installationId);

    const parsed: z.infer<typeof OutputSchema>["parsed"] = [];
    let failedCount = 0;

    // Process in batches of 10 to avoid rate-limiting
    const batchSize = 10;
    for (let i = 0; i < input.changed.length; i += batchSize) {
      const batch = input.changed.slice(i, i + batchSize);
      const results = await Promise.allSettled(
        batch.map(async (file) => {
          const blobRes = await octokit.request(
            "GET /repos/{owner}/{repo}/git/blobs/{file_sha}",
            { owner: repo.owner, repo: repo.name, file_sha: file.sha }
          );
          const content = Buffer.from(blobRes.data.content, "base64").toString("utf-8");

          const collection = extractCollection(file.path, repo.contentRoot);
          const result = parseMdxContent(file.path, content);

          return {
            filePath: file.path,
            gitSha: file.sha,
            collection,
            typed: result.typed as Record<string, unknown>,
            extras: result.extras,
            metadata: result.metadata as Record<string, unknown>,
            body: result.body,
          };
        })
      );

      for (const r of results) {
        if (r.status === "fulfilled") {
          parsed.push(r.value);
        } else {
          failedCount += 1;
          log.warn({ error: r.reason }, "Failed to parse file");
        }
      }
    }

    return { parsed, failedCount };
  }
}

/**
 * Extract collection name from path: src/content/blog/de/foo.mdx → "blog"
 */
function extractCollection(filePath: string, contentRoot: string): string {
  const root = contentRoot.replace(/^\/|\/$/g, "");
  const relPath = filePath.startsWith(root) ? filePath.slice(root.length + 1) : filePath;
  return relPath.split("/")[0] ?? "unknown";
}
```

**Step 5: LinkTranslationPairsStep**

Audits existing translationKey pairs. Logs orphans (articles whose translationKey doesn't have a pair). No DB changes — translationKey is the link itself.

```typescript
// packages/adapters/astro-sync/src/import/steps/link-translation-pairs.ts
import { articles, db } from "@marketing-auto/db";
import { BaseStep, type StepContext } from "@marketing-auto/pipelines/engine";
import { and, eq, sql } from "drizzle-orm";
import { z } from "zod";

const InputSchema = z.object({
  projectId: z.string().uuid(),
});

const OutputSchema = z.object({
  totalPairs: z.number(),       // pairs where both DE and EN exist
  orphans: z.number(),          // articles with translationKey but no pair
  unkeyed: z.number(),          // articles with no translationKey (solo, not part of a pair)
});

export class LinkTranslationPairsStep extends BaseStep<
  z.infer<typeof InputSchema>,
  z.infer<typeof OutputSchema>
> {
  readonly name = "link-translation-pairs";
  readonly inputSchema = InputSchema;
  readonly outputSchema = OutputSchema;

  override estimatedCostEur(): number { return 0; }

  async execute(input: z.infer<typeof InputSchema>, _ctx: StepContext) {
    // Group by translationKey
    const rows = await db
      .select({
        translationKey: articles.translationKey,
        count: sql<number>`count(*)::int`,
      })
      .from(articles)
      .where(and(eq(articles.projectId, input.projectId), eq(articles.source, "imported")))
      .groupBy(articles.translationKey);

    let totalPairs = 0;
    let orphans = 0;
    let unkeyed = 0;
    for (const r of rows) {
      if (!r.translationKey) {
        unkeyed += r.count;
      } else if (r.count >= 2) {
        totalPairs += 1;
      } else {
        orphans += 1;
      }
    }

    return { totalPairs, orphans, unkeyed };
  }
}
```

```typescript
// packages/adapters/astro-sync/src/import/trigger.ts
import { astroImportRuns, db, projects } from "@marketing-auto/db";
import { enqueuePipeline } from "@marketing-auto/pipelines/engine";
import { eq } from "drizzle-orm";

export async function enqueueRepoImport(input: {
  projectId: string;
  triggerSource: "manual" | "webhook" | "scheduled";
}): Promise<{ importRunId: string; jobId: string }> {
  const [project] = await db
    .select()
    .from(projects)
    .where(eq(projects.id, input.projectId))
    .limit(1);

  if (!project) throw new Error(`Project ${input.projectId} not found`);
  if (!project.astroRepo) {
    throw new Error(`Project ${input.projectId} has no astroRepo configured`);
  }

  // Pre-INSERT importRun row (idempotency-safe)
  const [run] = await db
    .insert(astroImportRuns)
    .values({
      projectId: input.projectId,
      status: "pending",
      triggerSource: input.triggerSource,
    })
    .returning();

  const { jobId } = await enqueuePipeline({
    pipelineName: "astro:repo-import",
    projectId: input.projectId,
    input: { projectId: input.projectId, importRunId: run!.id },
    jobOptions: { jobId: `repo-import-${run!.id}` },
  });

  return { importRunId: run!.id, jobId };
}
```

```typescript
      de: u.locale === "de" ? u : null,
```

## Discovered During Implementation

- **`drizzle-kit generate` is non-TTY incompatible** — it opens an interactive prompt and stalls indefinitely when run from Claude Code or CI. Migration SQL was written manually and `_journal.json` updated by hand (entry idx 14, when 1779200000000).

- **`cornerstoneKeyword` nullable cascade** — making the column nullable broke 5 downstream pipeline steps and API routes that assumed `string`. Required null-guard fixes in: `load-article.ts` OutputSchema, `ArticleSyncPipeline` commit message, `topic-intake.ts` (null guard + error throw), `load-candidates.ts` CandidateSchema, `clusters.ts` titleMap type, `pipeline-runs.ts` function signatures.

- **`UpdateImportRunStep` had no implementation in spec** — the spec's pipeline assembly listed this step but provided no implementation code. Written from scratch based on the `astroImportRuns` schema.

- **Pause + idempotency guard missing** — the spec's trigger route example omitted `checkTriggerAllowed`. Found during `/review-task` and fixed: the route now checks pause state and deduplicates against active `pipelineRuns` rows before calling `enqueueRepoImport`. When deduped, the existing active `astroImportRuns` row is looked up by `projectId + status` to return the correct `importRunId`.

## Deviations

- **`collection` and `locale` are `NOT NULL` with defaults instead of nullable** — the spec defined them as nullable (to match the spec's SQL comments: "nullable: collection, locale"). Changed to `NOT NULL DEFAULT 'blog'` / `NOT NULL DEFAULT 'de'` because PostgreSQL unique indexes treat `NULL != NULL`, meaning two rows with `NULL` collection/locale would never conflict and the unique constraint would be silently bypassed. Using `NOT NULL` with defaults preserves the constraint's intent. Existing generated articles are backfilled to these defaults in the migration.

- **Migration written manually** — the spec called for `bun --filter @marketing-auto/db drizzle-kit generate`. This was replaced with hand-written SQL + manual `_journal.json` update due to the non-TTY limitation (see Discovered above).
