# Design Reference

Mirror of the Claude Design handoff bundle for toolwiki.ai.

The canonical version lives at `.claude/skills/toolwiki-design/` — that is the
skill Claude Code sessions discover automatically. This mirror exists so
developers can inspect the HTML reference files in a browser without leaving
the repo, and so IDE search indexes the design files alongside the composition
source.

The two locations contain the same bundle. When Claude Design re-exports an
updated bundle, both locations are refreshed in one commit.

See `.claude/skills/toolwiki-design/SKILL.md` for the full rules and quick map.
See `bundle/REMOTION.md` for the authoritative prop schemas and field-length budgets.
